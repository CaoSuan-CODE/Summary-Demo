### 1. 概率公理（Kolmogorov's Axioms of Probability）

**直觉**：概率就是"给每个可能发生的事情配一个 0 到 1 之间的数字"，用来度量它有多可能发生；三条公理是这个配数字游戏必须遵守的三条基本规则。

**是什么**：设样本空间 Ω（sample space）是"所有可能结果"的集合，事件 A（event）是 Ω 的任意一个子集，P(A) 是分配给事件 A 的概率。1933 年柯尔莫哥洛夫（Kolmogorov）提出三条公理：
- 非负性（Non-negativity）：P(A) ≥ 0，任何事件的概率不小于 0；
- 归一性（Normalization）：P(Ω) = 1，整个样本空间的概率为 1；
- 可数可加性（Countable additivity）：对两两互斥（disjoint）的事件 A₁, A₂, …，有 P(A₁ ∪ A₂ ∪ …) = P(A₁) + P(A₂) + …，即互斥事件的概率直接相加。

**为什么**：在公理化之前，"概率"的定义众说纷纭（频率派说概率是长期频率，古典派说概率是等可能结果的比值）。公理化把概率从"哲学争论"变成"数学对象"：只要你定义的 P 满足这三条，剩下的所有概率规则都能严格推导出来，不必再纠结概率"到底是什么"。

**怎么用**：掷一颗均匀骰子，Ω = {1,2,3,4,5,6}。事件 A = "掷出偶数" = {2,4,6}。因为每个结果等可能且概率和为 1，所以 P(A) = 3/6 = 0.5。对任意事件，先把事件拆成互斥的基本结果，再逐项相加即可。

**类比**：概率公理就像"记账三原则"——不能记负账（非负性）、总资产必须等于总额（归一性）、互不重叠的账目要分开累加（可加性）。三条规则定下来后，所有复杂的账目处理都能由它们推出。

**易错点**：可加性只对"互斥"事件成立；两个事件有重叠时不能直接相加（见 kp-02 的并集公式）。

**前置**：无（本课程起点）。

### 2. 集合运算与概率规则（Set Operations & Probability Rules）

**直觉**：用集合的语言描述"或"与"且"，再配上两条加减规则，就能把任何复合事件的概率算出来。

**是什么**：给定事件 A、B：
- 补集（complement）Aᶜ：Ω 中不在 A 里的所有结果，P(Aᶜ) = 1 − P(A)；
- 并集（union）A ∪ B："A 或 B 发生（或同时发生）"；
- 交集（intersection）A ∩ B："A 与 B 同时发生"；
- 并集公式：P(A ∪ B) = P(A) + P(B) − P(A ∩ B)。

**为什么**：A ∪ B 若直接算 P(A) + P(B)，重叠区域 A ∩ B 会被算两次，所以要减去一次。这条公式是从三条公理推出的第一条"有用的推论"，也是后面所有计算的基石。

**怎么用**：掷骰子，A = "偶数" = {2,4,6}（概率 0.5），B = "≥4" = {4,5,6}（概率 0.5），A ∩ B = {4,6}（概率 2/6）。则 P(A ∪ B) = 0.5 + 0.5 − 2/6 = 2/3，即"偶数或 ≥4"的概率是 2/3。

**类比**：两个朋友圈的人数相加时，共同好友会被数两次，所以要减掉"共同好友"那一份。

**易错点**：只有 A、B 互斥（A ∩ B 为空）时才能省略最后一项；忘记减重叠是最常见的错误。

**前置**：见 kp-01（公理）。

### 3. 随机变量（Random Variables）

**直觉**：随机变量是"把随机结果翻译成数字"的翻译器——随机结果本身不是数字，翻译成数字才好计算。

**是什么**：随机变量 X 是一个函数，把样本空间里的每个结果映射到一个数。例如 X = "骰子显示的点数"，结果"掷出 3"映射为数字 3。约定大写 X 表示变量，小写 x 表示它实际取到的某个值（realized value）。按取值分为两类：
- 离散（discrete）X：取值有限或可数（如点击数、错误数、类别标签）；
- 连续（continuous）X：取值填满一个区间（如身高、响应时间、温度）。

**为什么**：事件只能谈"某件事发生不"，很难直接做加减乘除；把结果数字化之后，才能定义期望、方差、做统计推断，整个概率论和统计才运转得起来。

**怎么用**：X = 骰子点数，则 X 的可能取值是 {1,…,6}，每个取值概率 1/6，X 是离散随机变量；而"某服务器响应时间"是一个连续随机变量，取值可以落在 (0, ∞) 的任意实数上。

**类比**：随机变量像考卷上的"得分"——答题结果千差万别，但映射成分数后，才能算平均分、排名。

**易错点**：随机结果（outcome）≠ 随机变量（variable）；一个结果是"掷出了正面"，而随机变量是"正面对应的数字 1"。另外大写小写别混：X 是规则，x 是规则跑出来的某个数字。

**前置**：见 kp-01。

### 4. 概率质量函数、概率密度函数与累积分布函数（PMF, PDF & CDF）

**直觉**：离散用"概率质量"逐点给概率，连续用"概率密度"给面积、面积才是概率；CDF 则是一路累加（累积）到某点的总概率。

**是什么**：
- 离散 X：概率质量函数（probability mass function, PMF）P(X = x) 直接给出 X 恰等于 x 的概率。
- 连续 X：概率密度函数（probability density function, PDF）fₓ(x)；概率 = 曲线下的面积，而不是高度。P(a ≤ X ≤ b) = ∫ₐᵇ fₓ(x) dx。
- 累积分布函数（cumulative distribution function, CDF）：Fₓ(x) = P(X ≤ x)，表示"概率累计到 x 为止的总量"。

**为什么**：连续随机变量取值是无穷多个点，任何单个点的概率必须是 0（否则无穷多个正数相加会爆炸），所以连续情形必须用"面积"来谈概率——这正是"密度 ≠ 概率"的根源。CDF 则给了一个统一的、单调不减的"概率账户"。

**怎么用**：标准正态密度在 x=0 处高度约 0.4，但 P(X = 0) = 0；要问概率得问区间，比如 P(−1 ≤ X ≤ 1) 是密度曲线在 [−1,1] 下的面积。CDF 则是从 −∞ 一路积分到 x 的累计值。

**类比**：密度像一条"概率浓度曲线"——浓度高的地方只是说明附近概率堆积得多，但取一个无穷细的点，概率永远是 0；就像一根细针扎在湖面上，扎中的"面积"是 0。

**易错点**：经典误区——"密度值高 = 该点概率高"。连续随机变量单点概率恒为 0，密度高只代表该点附近区间概率更大。PMF 给的是概率本身，PDF 给的是密度，两者单位不同，不能直接比较数值。

**前置**：见 kp-03（随机变量）。

### 5. 期望与方差（Expectation & Variance）

**直觉**：期望是"长期平均下来 X 大概落在哪"，方差是"X 围绕这个中心晃得多厉害"。

**是什么**：
- 期望（expectation）E[X]：X 的长期平均值。
  - 离散：E[X] = Σₓ x · P(X = x)，即"每个取值乘它的概率再求和"；
  - 连续：E[X] = ∫ x fₓ(x) dx，即"取值乘密度后在整个数轴上积分"。
- 方差（variance）Var(X) = E[(X − E[X])²]，衡量 X 相对均值的离散程度。
- 标准差（standard deviation）σ = √Var(X)；σ 越大，波动越大。

**为什么**：只知道"最可能的值"不够，还必须知道"有多不确定"。两个分布可以有相同的均值（μ = 0）但完全不同的波动——σ=1 的曲线尖而集中，σ=2 的曲线扁而分散，后者代表更不确定、噪声更大的变量。

**怎么用**：掷均匀骰子，E[X] = Σₓ x·(1/6) = (1+2+…+6)/6 = 3.5，这是长期平均点数。伯努利试验中 X ~ Bernoulli(p)，E[X] = p（因为取 1 的概率是 p、取 0 的概率是 1−p），Var(X) = p(1−p)。

**类比**：期望像班级平均分，方差像"分数的参差程度"——两个班平均分相同，一个班分数都挤在平均分附近（方差小），另一个班高分低分两极分化（方差大）。

**易错点**：E[X] 不必是 X 能取到的值（骰子期望 3.5 就不是某个面）；方差单位是 X 单位的平方，所以常用标准差 σ 回到原单位来谈"波动"。

**前置**：见 kp-03、kp-04。

### 6. 独立性（Independence）

**直觉**：知道 A 发生与否，对 B 会不会发生毫无帮助——这就是独立。

**是什么**：若知道 A 已发生并不能给 B 带来任何新信息，则 A、B 独立，等价于 P(A ∩ B) = P(A) × P(B)。对随机变量：若对所有 x, y 都有 P(X=x, Y=y) = P(X=x)·P(Y=y)，则 X、Y 独立。

**为什么**：独立是极强的"建模假设"而非自动成立的客观事实。它能让联合概率分解成简单乘积，大幅简化计算，但也因此容易被滥用（见易错点）。

**怎么用**：掷硬币与掷骰子互相独立——知道硬币是正面，对骰子出几毫无信息，所以 P(正面 ∩ 出6) = (1/2)·(1/6) = 1/12。AI 中的朴素贝叶斯（Naive Bayes）正是假设"给定类别后各特征条件独立"，从而把高维联合概率拆成一堆低维乘积。

**类比**：独立像两个互不相干的闹钟——第一个响不响，不影响你对第二个会不会响的判断。

**易错点**：独立是建模假设，现实中变量常常相关（句子里的词、图像里的相邻像素都高度相关）。朴素贝叶斯"强行假设独立"常不成立，但模型依然透明、快、好用作基线——所以"假设不成立"不等于"模型不能用"。

**前置**：见 kp-02（并交规则）。

### 7. 条件概率（Conditional Probability）

**直觉**：把世界缩小到"只考虑 B 发生的那部分"，再在这个小世界里问 A 的概率。

**是什么**：已知 B 发生后，A 的概率记为 P(A|B)，定义为 P(A|B) = P(A ∩ B) / P(B)（要求 P(B) > 0）。分子是"A、B 同时发生"的概率，分母是"B 发生"的概率。

**为什么**：信息会改变概率。无条件时 A 的"世界"是整个 Ω，条件化后世界只剩 B 那一块，分母 P(B) 起"归一化"作用，把这块小世界的总概率重新调成 1。

**怎么用**：掷骰子，A = "偶数"，B = "≥4"。A = {2,4,6}，B = {4,5,6}，A ∩ B = {4,6}。P(A ∩ B) = 2/6，P(B) = 3/6，所以 P(A|B) = (2/6)/(3/6) = 2/3。解释：一旦知道点数 ≥4，它是偶数的机会从 1/2 升到 2/3。

**类比**：全年级及格率是 60%，但"只看重点班"及格率是 90%——"重点班"就是那个条件 B，条件化就是缩小统计范围再算比例。

**易错点**：P(A|B) 与 P(B|A) 完全不同（条件方向不能反）；若 A、B 独立，则 P(A|B) = P(A)，条件化不带来任何改变。

**前置**：见 kp-02、kp-06。

### 8. 全概率公式（Law of Total Probability）

**直觉**：把大问题拆成若干互斥且穷尽的"背景情况"，分别算再按比例加权平均，就得到总概率。

**是什么**：若 B₁, …, Bₙ 把样本空间完整且互斥地划分（partition），则 P(A) = Σᵢ P(A|Bᵢ)·P(Bᵢ)。即"总概率 = 各分支条件概率 × 该分支占比 的加权平均"。

**为什么**：很多时候直接算 P(A) 很难，但在每个子群内部算 P(A|Bᵢ) 反而容易。全概率公式提供"分而治之"的桥梁，也是贝叶斯定理分母的来源。

**怎么用**：某人群按年龄分三组：青年 50%（患病率 5%）、中年 30%（患病率 15%）、老年 20%（患病率 30%）。总患病率 P(disease) = 0.05×0.5 + 0.15×0.3 + 0.30×0.2 = 0.107，即总体患病率 10.7%，是各亚组的加权混合。

**类比**：全班平均分 = 男生平均分×男生比例 + 女生平均分×女生比例——按分组加权平均。

**易错点**：B₁,…,Bₙ 必须"互斥且穷尽"（恰好覆盖整个 Ω，没有重叠也没有遗漏），否则加权平均会算重或算漏。

**前置**：见 kp-07（条件概率）。

### 9. 贝叶斯定理（Bayes' Theorem）

**直觉**：把"已知原因推结果"（似然）倒过来，变成"已知结果反推原因"（后验），中间乘上你对原因的先验信念。

**是什么**：P(A|B) = P(B|A)·P(A) / P(B)。四个量各有名字：
- P(A)：先验（prior），看到证据前对 A 的信念；
- P(B|A)：似然（likelihood），A 为真时观察到证据 B 的概率；
- P(A|B)：后验（posterior），看到证据后更新过的信念；
- P(B)：证据（evidence），B 的总体发生概率，可用全概率公式展开 P(B) = P(B|A)P(A) + P(B|Aᶜ)P(Aᶜ)。
核心记法：后验 ∝ 先验 × 似然（posterior ∝ prior × likelihood）。它直接由乘积规则 P(A ∩ B) = P(A|B)P(B) = P(B|A)P(A) 推出。

**为什么**：AI 系统要"看到数据后更新判断"。贝叶斯定理把"新证据如何重塑旧信念"写成一条可复用的公式，是医学诊断更新、垃圾邮件过滤、信息检索的共同骨架。

**怎么用**（医学诊断例子）：患病率 P(disease) = 0.01，灵敏度 P(+|disease) = 0.90，假阳性率 P(+|no disease) = 0.05。求 P(disease|+)：
- 先验：P(disease)=0.01，P(no disease)=0.99；
- 证据：P(+) = 0.90×0.01 + 0.05×0.99 = 0.0585；
- 后验：P(disease|+) = 0.90×0.01 / 0.0585 ≈ 15.4%。
结论：检测阳性并不代表患病概率高达 90%，因为先验患病率低、健康人群基数大导致假阳性远超真阳性。用 10000 人验算：100 人患病中 90 真阳性，9900 健康人中 495 假阳性，阳性共 585 人，其中真正患病 90/585 ≈ 15.4%。

**类比**：先验是你出发时的成见，似然是证据"支持谁"的力度，后验是把成见按证据修正后的新判断；证据越多，后验越远离先验、越靠近事实。

**易错点**：把 P(+|disease) = 0.90（灵敏度）当成 P(disease|+) = 0.90（后验）——这是本课反复强调的经典误区。条件方向反了，结论天差地别。

**前置**：见 kp-07、kp-08。

### 10. 大数定律（Law of Large Numbers）

**直觉**：重复试验足够多次，平均值会"稳定地"逼近真实期望，个别结果依旧随机，但平均趋势越来越稳。

**是什么**：对独立同分布（i.i.d.）、均值有限为 μ 的随机变量，样本均值 X̄ₙ = (1/n)Σᵢ Xᵢ 满足 X̄ₙ → μ（n → ∞，几乎必然，almost surely）。课件用反复抛硬币示意：单次正反依旧随机，但正面比例随 n 增大越来越贴近 0.5。

**为什么**：它回答了"为什么频率能代表概率"——长期频率的稳定性正是大数定律保证的，是频率派统计与很多算法的哲学根基。

**怎么用**：抛 10 次硬币正面比例可能 0.40，抛 100 次可能 0.52，抛 1000 次可能 0.49，抛 10000 次约 0.51——n 从 10 到 10000，正面比例逐渐"定居"在 0.5 附近。样本均值收敛到 μ = 0.5。

**类比**：抽查学生成绩，抽 3 个人平均分忽高忽低，抽 3000 个人平均分就非常稳定地接近全校真实平均分。

**易错点**：大数定律不保证"输多了下次一定赢"（赌徒谬误）——它说的是"长期平均"收敛，而不是"个体结果会自我修正"；个体结果始终随机。

### 11. 中心极限定理（Central Limit Theorem）

**直觉**：不管原始数据长成什么奇怪形状，只要样本够大，把样本均值"标准化"后，它都会趋近标准正态分布。

**是什么**：从均值、方差都有限的分布里取 i.i.d. 样本，重复抽样并计算样本均值、再标准化。标准化的样本均值 Zₙ = (1/(σ√n)) Σᵢ (Xᵢ − μ) ⇒ Normal(0,1)（n 增大时）。等价地说：X̄ₙ 近似服从 Normal(μ, σ²/n)。课件展示了三种截然不同的源分布（Uniform(0,1)、Bernoulli(p=0.3)、Exponential(1)），它们的标准化样本均值在 n 增大时都收敛到同一条标准正态曲线。

**为什么**：它解释了为什么高斯曲线"到处都是"——许多微小的独立效应叠加后，其平均会呈现正态。也是置信区间、正态近似的基础；在 AI 里能解释深度学习中小批量梯度（minibatch gradient）的噪声行为，以及强化学习中回报估计的误差。

**怎么用**：不管数据是均匀的、0-1 的还是有偏的，只要样本量 n 够大（课件示意 n 从 1 到 100），标准化的样本均值就越来越像 N(0,1)。这就是用正态分布给"样本均值"配置信区间的依据。

**类比**：把很多独立的小扰动叠加（像无数颗小石子投入水面），无论每颗石子形状多怪，水面总波纹的平均高度分布最终都长成同一个"标准形状"——钟形。

**易错点**：CLT 不是说原始数据变正态，而是说"标准化的样本均值"趋近正态。原始数据可以完全不是高斯分布。

**前置**：见 kp-05、kp-10（大数定律：LLN 说均值收敛到哪里，CLT 说它波动的形状是什么）。

<a id="kp-12"></a>
### 12. 信息熵（Entropy）

**直觉**：熵是"结果有多不确定"的度量——结果越扑朔迷离，熵越高；几乎板上钉钉，熵接近 0。

**是什么**：熵 H(X) = −Σₓ P(X=x) log P(X=x)，对每个结果的概率取对数再加权求和再取负号。二值情形：熵最高在 p = 0.5（最大不确定，1 bit），p→0 或 p→1 时熵→0（几乎确定）。

**为什么**：熵给"不确定性"一个可计算、可优化的数字，是信息论的核心量。最大熵原理（maximum-entropy principle）说：在已知约束下，选"最不偏不倚"、即熵最大的那个分布——只承诺已知的信息，不额外假设。

**怎么用**：一枚均匀硬币 p=0.5 熵为 1 bit（最不确定）；一枚几乎总出正面的硬币 p=0.99 熵接近 0（几乎没悬念）。熵与逻辑回归、贝叶斯推理"不过度承诺"的思想松散相连。

**类比**：天气预报"明天 50% 下雨 50% 不下"最没信息量（熵最大）；"明天 99% 晴"几乎确定（熵极小）。

**易错点**：熵度量"不确定性"，其数值等于"平均需要多少个 bit 才能说清结果"；对连续变量熵的定义要用微分熵，别与离散熵混用。

**前置**：无（但用到对数的基本性质）。

<a id="kp-13"></a>
### 13. 分布选择总览（Choosing a Distribution: The Map）

**直觉**：给数据选模型像"对症下药"——先看数据类型，再选对应的分布家族。

**是什么**：课件给了一张"数据 → 分布"速查表：二值结果 → Bernoulli；n 次试验中的成功次数 → Binomial；区间内事件数 → Poisson；多类别 → Multinomial；有界连续值 → Uniform；钟形连续值 → Gaussian；等待时间 → Exponential；正偏态正值 → Gamma；一个概率参数 → Beta；一个概率向量 → Dirichlet。

**为什么**：分布不是"越熟越好"，而是"越贴合数据越好"。选错分布（misspecified distribution）会引入系统性偏差，比如用单个高斯去拟合多峰数据就会漏掉其他峰。

**怎么用**：拿到"用户每分钟到达数"用 Poisson，"用户是否点击广告"的概率用 Beta，"等待下一次服务器请求的时间"用 Exponential。决策树顺序：二值？→ Bernoulli；计数？→ Poisson；正连续？→ Exponential/Gamma；实值对称？→ Gaussian；一个概率？→ Beta；概率向量？→ Dirichlet。

**类比**：选分布像选容器——液体用瓶子、散货用箱子、粉末用罐子；容器不合适，装什么都漏。

**易错点**：别因为"高斯熟"就什么都用高斯；要考虑支撑集（support）、对称性、尾部、多峰性、样本量、可解释性。

**前置**：见 kp-03、kp-04（离散/连续的基本语言）。

<a id="kp-14"></a>
### 14. 伯努利分布（Bernoulli Distribution）

**直觉**：一次"是/否"试验的概率模型。

**是什么**：X ~ Bernoulli(p)：P(X=1) = p，P(X=0) = 1−p。参数 p 是"成功"概率。E[X] = p，Var(X) = p(1−p)。假设：两个互斥结果、各次重复间 p 固定。

**为什么**：它是所有 0-1 试验的原子模型，二项、Beta 等都在它之上搭建；AI 中垃圾标签、dropout 掩码、sigmoid 输出都是伯努利。

**怎么用**：一次点击，p=0.3 表示 30% 概率点击、70% 不点击。方差 p(1−p) 在 p=0.5 时最大（最不确定），p→0 或 1 时最小。

**类比**：抛一次硬币——正反两个结果，一个概率 p 全说了算。

**易错点**：它只能表示两个结果，且 p 在重复间固定；若 p 随时间变（时变点击率），单一 Bernoulli 就不够，要用 Beta 去描述 p 本身的不确定性（见 kp-21）。

**前置**：见 kp-03。

<a id="kp-15"></a>
### 15. 二项分布（Binomial Distribution）

**直觉**：n 次独立伯努利试验里，"成功"总共出现几次。

**是什么**：Y ~ Binomial(n, p)：P(Y=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ，其中 C(n,k) = n!/(k!(n−k)!) 是二项式系数（n 次里选 k 次成功的位置数）。E[Y] = np，Var(Y) = np(1−p)。

**为什么**：把"多次独立 0-1 试验"聚合成一个总数，是 A/B 测试、质量抽检的基础模型。

**怎么用**：n=20 个用户、每人点击概率 p=0.3，点击总数 Y ~ Binomial(20, 0.3)，期望 6 次点击。P(Y=k) 用公式逐项算，或查分布表。

**类比**：抛 20 次硬币数正面——每次是伯努利，总数是二项。

**易错点**：前提是各次独立且 p 恒定；社交传染或人群变化会破坏这个假设。二项是"相互独立"的计数，与不放回抽样的超几何分布不同。

**前置**：见 kp-14（伯努利）。

<a id="kp-16"></a>
### 16. 泊松分布（Poisson Distribution）

**直觉**：单位时间/空间里"稀疏、独立事件"发生次数的模型。

**是什么**：Z ~ Poisson(λ)：P(Z=k) = λᵏ e⁻λ / k!，其中 λ 是单位区间的平均事件数。E[Z] = Var(Z) = λ。

**为什么**：很多真实计数是"稀有的独立到达"（点击/分钟、服务器请求、词出现次数），泊松用单个参数 λ 就抓住了它，且均值=方差是它的标志。

**怎么用**：λ = 4 表示平均每分钟 4 次请求；P(Z=0) = e⁻⁴ ≈ 0.018，P(Z=1) = 4e⁻⁴ ≈ 0.073，依此类推。

**类比**：便利店每分钟进店人数——稀疏、独立、速率均匀时，人数服从泊松。

**易错点**：要求速率均匀（泊松过程）；高峰期速率变化或事件互相抑制（一个来了另一个不来）时泊松失效。当 n 大、p 小且 np = λ 固定时，二项近似泊松——这是泊松与二项的联系。

**前置**：见 kp-14、kp-15。

<a id="kp-17"></a>
### 17. 多项分布（Multinomial Distribution）

**直觉**：把"二分类"推广到 K 类——n 次独立试验里，各类别各出现几次。

**是什么**：P(N₁=k₁,…,N_K=k_K) = n!/(k₁!…k_K!) · ∏ᵢ pᵢᵏⁱ，其中 Nᵢ 是第 i 类出现的次数，pᵢ 是第 i 类概率（Σ pᵢ = 1）。E[Nᵢ] = npᵢ。

**为什么**：词计数、主题模型计数、softmax 类别的重复试验都需要它；一次试验的类别分布（categorical）由 softmax 参数化，重复类别试验的计数则服从多项分布。

**怎么用**：4 类主题概率 (0.40, 0.30, 0.20, 0.10)，做 n=100 次抽样，各类期望计数为 (40, 30, 20, 10)。

**类比**：一个多面骰子掷 n 次，记录每个面各出现几次——那就是多项分布。

**易错点**：类别概率在各次试验间恒定；无法刻画顺序或概率漂移，需要顺序模型（HMM、RNN）才能处理。

**前置**：见 kp-15（二项：K=2 时的特例）。

<a id="kp-18"></a>
### 18. 均匀分布（Uniform Distribution）

**直觉**：区间内每个值"一视同仁"、等可能。

**是什么**：fᵤ(x) = 1/(b−a)（x ∈ [a,b]），其余为 0。E[U] = (a+b)/2，Var(U) = (b−a)²/12。

**为什么**：它是"无信息"的连续基准；AI 里用于权重初始化、动作探索、蒙特卡洛采样、随机图像裁剪。

**怎么用**：U ~ Uniform(0,1) 的密度是 1（区间长度 1）；落在 [0.2, 0.5] 的概率 = 0.3（面积 = 高 × 宽 = 1 × 0.3）。

**类比**：转盘均匀分格，指针落在任何位置的"密度"都一样。

**易错点**：真实数据很少是均匀的；且整个实数轴上不存在真正的均匀分布（无法归一化），"均匀"只能在有限区间上谈。

**前置**：见 kp-04（PDF）。

<a id="kp-19"></a>
### 19. 正态分布（Normal / Gaussian Distribution）

**直觉**：大自然里最常见的"钟形曲线"，由中心 μ 和宽度 σ 两个参数完全决定。

**是什么**：fₓ(x) = 1/(σ√(2π)) · exp(−(x−μ)²/(2σ²))。μ 是曲线的中心（位置参数），σ 是曲线的宽度（尺度参数）。对称、单峰、轻尾、定义在整个实数轴；μ=0, σ=1 时称为标准正态 Normal(0,1)。

**为什么**：CLT（kp-11）保证大量独立小效应之和趋近正态，所以它在统计和 AI 里无处不在：线性回归误差、高斯朴素贝叶斯、高斯混合模型（GMM）、卡尔曼滤波、VAE 隐变量、GAN 输入噪声。

**怎么用**：μ=0, σ=1 的标准正态，约 68% 概率落在 [−1,1]，约 95% 落在 [−2,2]（经验法则）。μ 平移曲线、σ 拉宽曲线。

**类比**：全班身高的分布——μ 是平均身高，σ 是"高矮参差"程度；对称单峰，中间多两头少。

**易错点**：不是所有数据都高斯——重尾数据（金融）、非负数据（时长）、多峰数据（簇）都会打破高斯假设。多峰图像像素强度就无法用单个高斯描述，需要混合模型。

**前置**：见 kp-04、kp-11。

<a id="kp-20"></a>
### 20. 指数分布与伽马分布（Exponential & Gamma Distributions）

**直觉**：指数分布是"无记忆过程的等待时间"；伽马分布是"等到第 α 个事件"的等待时间，指数是它的特例。

**是什么**：
- 指数：f_T(t) = λe^(−λt)，E[T] = 1/λ，Var(T) = 1/λ²；
- 伽马：形状参数 α、尺度参数 β，E[X] = αβ，Var(X) = αβ²；整数 α 时可看作泊松过程中等到第 α 个事件的时间；指数 = 伽马的 α = 1 特例。

**为什么**：等待时间、寿命、服务时间常需要这类"非负、右偏"的分布；指数是无记忆的（已等了多久不影响还要等多久），伽马/威布尔可放松这一假设。

**怎么用**：服务器平均 1/λ 小时来一个请求，等待时间 T ~ Exp(λ)；若想描述"第 α 个请求到达的时间"，用 Gamma(α, β)。

**类比**：指数像"下一次公交车来的等待时间"（无记忆——等多久了都还得平均再等同样久）；伽马像"凑齐第 α 位顾客到店的时间"。

**易错点**：无记忆假设常失效（老化产品、公交车都"有记忆"），此时用 Gamma/Weibull 修正。

**前置**：见 kp-16（泊松过程）、kp-04。

<a id="kp-21"></a>
### 21. 贝塔分布（Beta Distribution）

**直觉**：Bernoulli 描述"一次结果"，Beta 描述"对概率 p 本身的不确定"——活在 [0,1] 上。

**是什么**：Beta(α, β) 定义在 [0,1]，描述某个概率参数 p 的不确定性；α、β 像"先验计数"参数。当 α, β > 1 时，α−1 和 β−1 可近似理解为"先验成功次数"和"先验失败次数"。后验均值 E[p] = α/(α+β)。

**为什么**：很多 AI 问题问的不是"这次成不成"，而是"真实点击率是多少"——这是 Beta 问题而非 Bernoulli 问题。Beta 还是 Bernoulli/Binomial 似然的共轭先验，使更新有闭式解（见 kp-22）。

**怎么用**：Beta(2,2) 表示"对点击率先验相信大约 0.5，但不太确定"；Beta(10,2) 表示"更确信点击率偏高"（均值 10/12 ≈ 0.83）。Beta(1,1) 就是 [0,1] 上的均匀分布。

**类比**：Bernoulli 是"掷一次硬币记正反"，Beta 是"对硬币本身是不是偏心、偏心多少"的信念分布。

**易错点**：别把 Beta 与 Bernoulli 混为一谈——一个建模结果，一个建模概率参数本身；Beta 的支撑集是 [0,1]，不描述结果值。

**前置**：见 kp-14（伯努利）、kp-18（均匀，Beta(1,1)）。

<a id="kp-22"></a>
### 22. 共轭先验（Conjugate Priors）

**直觉**：先验和似然"门当户对"——先验乘上似然后，后验还是同一家族的分布，只是参数平移了，于是更新又快又准。

**是什么**：若先验 p(θ) 与似然 p(D|θ) 属于"共轭"配对，则后验 p(θ|D) 与先验同族，只需更新参数。核心例子（贝塔-伯努利更新）：先验 Beta(α, β)，观测到 s 次成功、f 次失败，后验 = Beta(α+s, β+f)。

**为什么**：共轭性让贝叶斯更新"解析且快速"——不用数值积分，直接把计数加进参数即可，是许多在线学习与贝叶斯系统能实时运转的原因。

**怎么用**：先验 Beta(2,2)（先验均值 0.5），观测 8 成功 2 失败，则 α_new = 2+8 = 10，β_new = 2+2 = 4，后验 Beta(10,4)，均值 10/14 ≈ 0.71——后验从 0.5 右移到 0.71，且更尖（更确定）。其他共轭对：Dirichlet-Multinomial（Dirichlet(α) + 类别计数 k → Dirichlet(α+k)）、Gamma-Poisson（Gamma 先验 + 泊松计数 → 更新后的 Gamma 后验）。

**类比**：共轭先验像"同一套乐高"——先验和后验是同一种积木，数据只是把积木块数改了改，不用换整套零件。

**易错点**：不是所有似然都有共轭先验；没有共轭形式时，要靠 MCMC、重要性采样或变分推断去近似后验（见 kp-30）。

**前置**：见 kp-09（贝叶斯）、kp-21（贝塔）。

<a id="kp-23"></a>
### 23. 狄利克雷分布（Dirichlet Distribution）

**直觉**：Beta 描述"一个概率（两类）"，Dirichlet 描述"K 类的概率向量"——是 Beta 的多类推广。

**是什么**：Dirichlet(α) 定义在单纯形（simplex）{zᵢ ≥ 0, Σᵢ zᵢ = 1} 上，参数 α = (α₁,…,α_K) 是各类的集中度（concentration）参数。E[zᵢ] = αᵢ / Σⱼ αⱼ。等集中度参数 = 对称先验；某类 αᵢ 大则偏向该类。

**为什么**：主题模型（LDA）、多项平滑、贝叶斯朴素贝叶斯都需要对"整条概率向量"表达不确定，Dirichlet 正是这个角色；它是 Multinomial 的共轭先验。

**怎么用**：Dirichlet 的一个样本就是三角形（3 类时）里的一个点——一条完整的、加和为 1 的概率向量。

**类比**：Beta 是"一个硬币偏不偏心"，Dirichlet 是"一个多面骰子每面概率是多少"的信念分布。

**易错点**：Dirichlet 各分量之间此消彼长（加和恒为 1），不是独立变量；α 是集中度，α 越大分布越"尖"地集中在期望向量附近。

**前置**：见 kp-21（贝塔）、kp-17（多项）。

<a id="kp-24"></a>
### 24. 指数族（Exponential Family）

**直觉**：Bernoulli、Binomial、Poisson、Normal、Exponential、Gamma、Beta、Dirichlet 看起来各不同，其实都是同一副"骨架"——指数族。

**是什么**：统一形式 f(x; η) = h(x) exp(η · T(x) − A(η))。参数含义：η 是自然参数（natural parameter），T(x) 是充分统计量（sufficient statistic），A(η) 是对数配分函数（log-partition function，起归一化作用），h(x) 是基测度。

**为什么**：AI/统计偏爱这个家族，因为它带来计算便利、充分统计量（只用 T(x) 就概括全部数据信息）、共轭先验、以及广义线性模型（GLM）的统一框架。

**怎么用**：以 Bernoulli 为例改写进指数族，可得到其自然参数 η = log(p/(1−p))（对数几率），T(x) = x——这正是 sigmoid/逻辑回归里出现 logit 的深层原因。

**类比**：指数族像"所有常见分布共用的一张标准表格"——换个 η、T、A 就换一种分布，但表格格式不变。

**易错点**：不是所有分布都属于指数族（如带未知参数的均匀分布、某些重尾分布就不在族内）；A(η) 不是装饰，它保证概率归一。

**前置**：见 kp-14~kp-23（各分布实例）。

<a id="kp-25"></a>
### 25. 分布选择的决策树（Model Selection: A Distribution Is an Assumption）

**直觉**：一个分布就是一种"假设"，选错假设会系统性地误导结论——所以按数据特征走决策树来选。

**是什么**：决策树问题链：二值？→ Bernoulli；计数？→ Poisson（备选负二项）；正连续？→ Exponential/Gamma；实值对称？→ Gaussian（基线）；一个概率？→ Beta；概率向量？→ Dirichlet。

**为什么**：错设的分布（如单高斯套多峰数据）引入系统偏差，比随机噪声更危险——它让模型"天生就错"，而且错得一致。

**怎么用**：先别急着上高斯；依次问支撑集、对称性、尾部、多峰性、独立性、样本量、可解释性，再定分布。数据多峰就上混合模型，数据非负就用 Gamma/Exp，概率就用 Beta/Dirichlet。

**类比**：选分布像选衣服尺码——不是"你熟哪个码就穿哪个码"，而是"按身材量体裁衣"。

**易错点**："高斯熟"是心理偏好，不是统计理由；单高斯套多峰数据会漏掉整片模式。

**前置**：见 kp-13（分布总览）、kp-24。

<a id="kp-26"></a>
### 26. 最大似然估计（Maximum Likelihood Estimation, MLE）

**直觉**：哪个参数让"我们真的看到这组数据"这件事最可能发生，就选哪个参数。

**是什么**：θ̂_MLE = argmax_θ p(D|θ)，即选使观测数据似然最大的 θ。i.i.d. 数据下似然 L(θ;D) = ∏ᵢ p(xᵢ|θ)；通常最大化对数似然 log L = Σᵢ log p(xᵢ|θ)（乘积变求和，求导更易、数值更稳）。各符号：D = {x₁,…,xₙ} 是观测数据，θ 是未知参数（如高斯的 μ,σ 或泊松的 λ），p(xᵢ|θ) 是单点似然。

**为什么**："让数据看起来最合理"是极自然的估计准则；它有一系列好的大样本性质（一致性、渐近正态、可达克拉美-罗下界，见 kp-45）。

**怎么用**（伯努利例子）：100 用户 70 点击，估计点击率 p。L(p) = p⁷⁰(1−p)³⁰，对数似然 ℓ(p) = 70 log p + 30 log(1−p)，令导数为零：70/p − 30/(1−p) = 0 ⇒ p̂ = 70/100 = 0.70。MLE 就是观测到的成功比例——这也是神经网络交叉熵训练的本质：最小化交叉熵 = 最大化似然。

**类比**：破案时找"最能让现场证据成立"的那个嫌疑人——MLE 就是找"最能让数据成立"的参数。

**易错点**：MLE 只给点估计，不给不确定性；小样本下可能有偏、方差大；边界情况（伯努利全成功）会给出 p̂=1 而没有自动的不确定性度量。

**前置**：见 kp-04、kp-14。

<a id="kp-27"></a>
### 27. 高斯模型的最大似然估计（Gaussian MLE）

**直觉**：在高斯模型下，"样本均值"和"MSE 最小"都不是巧合，而是最大似然的必然结果。

**是什么**：对高斯数据，MLE 给出 μ̂ = x̄ = (1/n)Σᵢ xᵢ（样本均值），σ̂²_MLE = (1/n)Σᵢ (xᵢ − x̄)²（分母 n 的方差）。注意无偏样本方差用分母 n−1，MLE 用 n。

**为什么**：这解释了"均值为什么在统计和 ML 里无处不在"——高斯模型下样本均值就是 μ 的最大似然估计；也解释了 MSE 损失的流行：若回归误差服从高斯，最大化似然 ≡ 最小化均方误差（MSE），两者是同一个优化问题。

**怎么用**：对 n 个样本算平均即得 μ̂；算离差平方和除以 n 即得方差 MLE（想无偏则除以 n−1）。

**类比**：MSE 不是"拍脑袋定的损失"，而是"假设误差高斯"后自然长出来的损失。

**易错点**：MLE 方差分母是 n，会略微低估真实方差（有偏），无偏估计用 n−1；这是"有偏但似然最大"与"无偏"的经典取舍。

**前置**：见 kp-26（MLE）、kp-19（高斯）。

<a id="kp-28"></a>
### 28. 矩估计法（Method of Moments, MoM）

**直觉**：让"理论矩"等于"样本矩"，解方程求出参数。

**是什么**：第 r 阶理论矩 mᵣ(θ) = E_θ[Xʳ]，样本矩 m̂ᵣ = (1/n)Σᵢ xᵢʳ；令两者相等，解出 θ 即得 θ̂_MOM。

**为什么**：很多分布参数恰好由矩表达（如泊松 λ = 均值），矩估计常比似然简单，避免复杂的似然函数。

**怎么用**：泊松均值估计 λ̂ = 样本均值；伯努利频率估计 p̂ = 样本比例——都是一阶矩直接给出。

**类比**：用"平均分"反推"题目难度参数"——拿看得见的统计量去解看不见的参数。

**易错点**：矩估计可能比 MLE 效率低，可能给出非法参数值（如估计出负的方差），高阶矩噪声大。

**前置**：见 kp-05（期望）、kp-26（MLE 对照）。

<a id="kp-29"></a>
### 29. 最大后验估计（Maximum A Posteriori, MAP）

**直觉**：MLE 只看数据；MAP 让"先验信念"也参与投票，把估计往先验方向"锚"一下。

**是什么**：θ̂_MAP = argmax_θ p(D|θ)·p(θ)，即最大化"似然 × 先验"。相比 MLE 只最大化 p(D|θ)，MAP 多乘一项先验 p(θ)。正则化的对应：权重的高斯先验 → L2 惩罚 → 岭回归（ridge）；权重的拉普拉斯先验 → L1 惩罚 → 套索回归（lasso）。一句话：正则化 = 用优化惩罚表达的"先验信念"。

**为什么**：数据很少时 MLE 会过拟合、估计乱跳；先验能稳住估计，尤其在小样本下价值大。

**怎么用**：只有 5 个观测但先验很强时选 MAP 而非 MLE——先验把估计锚在合理区域。线性回归加 L2 惩罚等价于给权重高斯先验，加 L1 惩罚等价于拉普拉斯先验（L1 还诱导稀疏）。

**类比**：MLE 是"只信数据"，MAP 是"数据 + 专家经验"——经验在数据少时拉你一把。

**易错点**：MAP 仍是"单点估计"，不给完整不确定性；且先验选得不好会系统性带偏结果。

**前置**：见 kp-26（MLE）、kp-09（贝叶斯）。

<a id="kp-30"></a>
### 30. 完整贝叶斯推断（Full Bayesian Inference）

**直觉**：不把 θ 当成一个"确定的未知数"，而是把它当成随机变量，输出一整条后验分布，从而保留不确定性。

**是什么**：后验 p(θ|D) = p(D|θ)p(θ) / p(D)；后验预测（posterior predictive）p(x_new|D) = ∫ p(x_new|θ) p(θ|D) dθ——对 θ 的所有可能取值做加权平均，而不是假装 θ 恰好等于某个点。当积分不可解析时，用 MCMC、重要性采样、变分推断近似（本课不深入）。

**为什么**：点估计（MLE/MAP）丢掉了"我们有多不确定 θ"；完整贝叶斯把这种不确定显式地带进预测，回答"模型有多没把握"。

**怎么用**：对 θ 的每个可能值按后验加权，把所有候选预测平均起来，得到后验预测分布——预测自带不确定性。

**类比**：MLE/MAP 是"押一个数字"，完整贝叶斯是"持有整条概率曲线"——曲线宽说明没把握，窄说明有把握。

**易错点**：后验预测不是"把 θ̂ 代入再预测"，而是"对所有 θ 加权平均"；近似方法各有偏差-效率权衡，不能当精确解用。

**前置**：见 kp-29（MAP）、kp-22（共轭先验）。

<a id="kp-31"></a>
### 31. 生成模型与判别模型（Generative vs. Discriminative Models）

**直觉**：判别模型"从 x 直奔 y"，生成模型"先学会 x 是怎么来的，再顺带推 y"。

**是什么**：
- 生成模型（generative）：学 p(x,y) 或 p(x)，能生成数据、建模输入分布、处理缺失数据；例子：朴素贝叶斯。
- 判别模型（discriminative）：直接学 p(y|x) 或决策边界（decision boundary），只关心从 x 预测 y，不建模 x 如何生成；例子：逻辑回归、深度分类器。

**为什么**：任务不同选不同——只想分类就用判别（通常更直接、样本效率高）；想生成、补全、或利用输入分布就用生成。

**怎么用**：垃圾邮件分类用判别（直接 p(spam|words)）也行，但朴素贝叶斯走生成路线（学 p(words|spam) 和 p(spam)）。图中"生成 y→x、判别 x→y"是直觉方向，不是严格的数学方向。

**类比**：判别模型像"看症状下诊断"的熟练医生（直奔结论）；生成模型像"先学会疾病的完整病理，再推导诊断"的教科书。

**易错点**：箭头图只是直觉；严格说判别学 p(y|x)，生成学联合 p(x,y)，两者是从联合分布分解的不同方向看同一件事。

**前置**：见 kp-09（贝叶斯/朴素贝叶斯）。

<a id="kp-32"></a>
### 32. 贝叶斯网络（Bayesian Networks）

**直觉**：用"有向图"把变量之间的依赖关系画出来，让联合概率能按图分解。

**是什么**：节点 = 随机变量，边 = 依赖关系。联合分布分解为 P(x₁,…,xₙ) = ∏ᵢ P(xᵢ | Parents(xᵢ))，即每个变量只依赖其父节点（parents）。给定父节点，节点与其非后代条件独立。例子：Disease 是父节点，Cough、Fever、Test 依赖它——观察到"发烧"和"测试阳性"会通过共享父结构更新 P(Disease)，本质是贝叶斯定理在图上运行。

**为什么**：全联合分布维度爆炸（n 个变量要 2ⁿ 项），图结构把联合分布压缩成局部条件概率的乘积，可计算、可解释。

**怎么用**：症状→疾病的诊断网络里，看到 Fever 和阳性 Test，就沿图用贝叶斯更新 P(Disease)，把多个证据合并成一个后验。

**类比**：家族遗传图——每个孩子（变量）只依赖父母（父节点），知道父母状态就能推孩子，不用回溯整本族谱。

**易错点**：有向边表达条件依赖/生成方向，未必是严格因果；"给定父节点后与非后代独立"是核心结构性质。

**前置**：见 kp-09、kp-06。

<a id="kp-33"></a>
### 33. 马尔可夫随机场（Markov Random Fields, MRF）

**直觉**：无向图表达"对称的相容性约束"——邻居之间互相拉扯，谁和谁更像。

**是什么**：无向边表达对称的相容性（compatibility），不是因果方向。分布 P(x) = (1/Z) ∏_C Ψ_C(x_C)，其中 Ψ_C 是团（clique）C 上的势函数（potential function），Z 是归一化常数（常很难精确计算）。贝叶斯网络：有向、偏因果；MRF：无向、相容约束。图像分割中相邻像素标签倾向一致，正是这种无向相容。

**为什么**：很多关系是"对称的"（相邻像素、相邻词），没有明确方向，用无向图更自然。

**怎么用**：图像分割——相邻像素颜色相近则倾向同标签，每个像素通过与邻居的势函数互相强化，形成平滑分割。

**类比**：一群人的座位安排——相邻两人关系好（相容）就挨着坐，是"双向拉扯"而非"谁指挥谁"。

**易错点**：Z 常是全局求和、难精确算，实际常用近似（如能量最小化/图割，见 kp-42）；别把无向的相容当成有向的因果。

**前置**：见 kp-32（贝叶斯网络对照）。

<a id="kp-34"></a>
### 34. 马尔可夫链（Markov Chains）

**直觉**：未来只取决于现在，不取决于全部历史——"今天决定明天，昨天靠边站"。

**是什么**：一阶马尔可夫假设 P(sₜ | sₜ₋₁, sₜ₋₂, …) = P(sₜ | sₜ₋₁)。关键参数：初始分布（initial distribution）+ 转移矩阵 aᵢⱼ = P(sₜ = j | sₜ₋₁ = i)（从状态 i 到 j 的一步转移概率）。

**为什么**：把"无限长的历史依赖"砍成"只看上一步"，让序列建模变得可处理，是 HMM、强化学习、随机过程的基础。

**怎么用**：天气"明天只取决于今天"：转移矩阵给出 Sunny→Rainy、Rainy→Cloudy 等概率，链上每一步只看当前状态。

**类比**：下棋时的"当前局面"——接下来怎么走只看现在棋盘，不必重放整盘历史。

**易错点**：一阶假设是近似，真实系统可能有更长程记忆；转移矩阵每行是概率、行和为 1。

**前置**：见 kp-06（独立性）、kp-07（条件概率）。

<a id="kp-35"></a>
### 35. 隐马尔可夫模型（Hidden Markov Models, HMM）

**直觉**：状态看不见（隐藏），只能看见它"发射"出来的观测——要从观测反推隐藏状态。

**是什么**：隐藏状态 s₁→s₂→…，每个状态发射观测 oₜ。联合分布 P(s₁:T, o₁:T) = P(s₁)P(o₁|s₁) ∏ₜ P(sₜ|sₜ₋₁)P(oₜ|sₜ)。例子：隐藏 = 用户意图（观测 = 点击/搜索/购买）；或隐藏 = 音素（观测 = 音频信号）。

**为什么**：现实中大量"状态不可见、只能看表象"的问题（意图、语音、天气）需要 HMM 这套"隐状态 + 发射"结构。

**怎么用**：三大经典算法各司其职——前向算法（Forward）算 P(o₁:T)（观测序列的总概率）；维特比算法（Viterbi）找最可能的隐藏状态序列；Baum-Welch（EM）从数据学习模型参数。本课只要求知道"每个算法是干什么的"。

**类比**：看一个人每天带不带伞（观测），反推天气（隐状态）——状态是"晴/雨"，观测是"伞"。

**易错点**：隐状态不是观测本身；三大算法用途不同，别把"求序列概率"与"求最可能状态路径"混为一谈。

**前置**：见 kp-34（马尔可夫链）、kp-26（EM/MLE）。

<a id="kp-36"></a>
### 36. Softmax、交叉熵与校准（Softmax, Cross-Entropy & Calibration）

**直觉**：softmax 把原始分数转成"加和为 1 的分数"，交叉熵训练等价于最大似然；但 softmax 的输出不自动是"可信的概率"，需要校准。

**是什么**：softmax：p̂ₖ = exp(zₖ) / Σⱼ exp(zⱼ)，把 logits（原始分数 z₁,z₂,z₃）归一化为概率向量。交叉熵训练 = 对正确类别的最大似然估计。校准（calibration）检查：模型说"80% 置信"的预测里，是否真有约 80% 正确；温度缩放（temperature scaling）可修正过/欠自信的 softmax 输出。

**为什么**：分类器输出一个数字容易，但这个数字"能不能当概率信"是另一回事——校准让置信度与真实正确率对齐。

**怎么用**：logits (2.0, 1.0, 0.1) 过 softmax 得约为 (0.66, 0.24, 0.10)，各类分数归一化；训练用交叉熵损失（= 正确类别的负对数似然）。

**类比**：softmax 像"把三个候选人的票数换算成百分比"；校准像"检查天气预报说 80% 下雨的日子，是不是真下了约 80%"。

**易错点**：softmax 分数不是自动校准的概率——模型可能"过度自信"（说 99% 其实只对 80%）。

**前置**：见 kp-17（多项/类别分布）、kp-26（MLE）。

<a id="kp-37"></a>
### 37. Dropout 与贝叶斯神经网络（Dropout & Bayesian Neural Networks）

**直觉**：Dropout 在训练时随机关掉神经元（伯努利掩码），同一输入跑多次会得到不同输出——输出散布得越开，模型越不确定。

**是什么**：Dropout 用伯努利随机掩码禁用单元，概率直接住在网络内部。蒙特卡洛 Dropout（Monte Carlo dropout）：同一输入做多次随机前向传播，用输出散布估计预测不确定性。贝叶斯神经网络（BNN）更一般：给权重 w 放先验，推断后验 p(w|D)，能指出模型"哪里不知道"，但计算昂贵。

**为什么**：深度学习想回答"我不确定多少"，而不仅是"我预测什么"——Dropout/BNN 把不确定性量化出来，对安全关键场景很重要。

**怎么用**：同一输入 x 用三个不同 dropout 掩码跑三次前向，得到三个略不同的输出；输出方差大 = 该输入附近模型没把握。

**类比**：问三个略有不同的"专家小组"（每次随机缺席几个专家），答案一致说明有把握，答案分歧大说明没底。

**易错点**：Dropout 训练时随机、测试时通常要缩放或做多次采样；BNN 精确推断难，计算开销大。

**前置**：见 kp-14（伯努利）、kp-30（贝叶斯推断）。

<a id="kp-38"></a>
### 38. 生成对抗网络与变分自编码器（GANs & VAEs）

**直觉**：GAN 和 VAE 都是"从噪声造数据"的概率生成模型，但一个隐式地逼近分布，一个显式地最大化证据下界。

**是什么**：
- GAN：生成器 G(z) 从隐噪声 z 造样本，目标是让生成分布 P_g 逼近真实数据分布 P_data；是隐式分布（无显式似然），可能出现模式坍塌（mode collapse，漏掉真实分布的某些模式）。
- VAE：隐变量 z、先验 p(z)、解码器 p(x|z)、编码器 q(z|x)；训练最大化 ELBO（证据下界）：
  L(θ,φ) = E_{qφ(z|x)}[log p_θ(x|z)] − D_KL(qφ(z|x) ‖ p(z))。
  第一项重构（reconstruction）拟合数据，第二项 KL 正则化让后验贴近先验。

**为什么**：两种主流概率生成模型，各有利弊：VAE 有显式似然、可做推断，样本偏模糊；GAN 样本锐利但无显式似然、易模式坍塌、难训练。

**怎么用**：VAE 流程 z ~ p(z) → 解码器 → x（生成），同时 x → 编码器 q(z|x)（推断）；GAN 流程 z → G(z) → x。

**类比**：VAE 像"学一套压缩-解压规则，再按规则仿制"；GAN 像"造假者与鉴伪者互相博弈，直到假货以假乱真"。

**易错点**：GAN 的 P_g ≈ P_data 是隐式的，没有显式似然可算；模式坍塌 = 生成器只学会少数几个模式，多样性不足。

**前置**：见 kp-31（生成模型）、kp-12（熵/KL 相关）。

<a id="kp-39"></a>
### 39. 案例：朴素贝叶斯垃圾邮件过滤（Naive Bayes Spam Filtering）

**直觉**：把邮件每个词当"证据"，用贝叶斯定理拼出"这是垃圾邮件的概率"。

**是什么**：P(Y=spam | x) ∝ P(Y=spam) ∏ᵢ P(Xᵢ=xᵢ | Y=spam)。先验 = 垃圾邮件占比 P(spam)；词似然 = P(word|spam) 从训练数据估计；后验 = 给定词后的垃圾概率。决策：选后验更大的类别，报告垃圾概率，设定阈值（如 0.9）自动拦截。拉普拉斯平滑（Laplace smoothing）避免某词在训练里没见过导致概率为 0。

**为什么**：独立性假设虽强，但模型透明、快、难以被打败，是极好的基线；能给出"概率"而非只有"标签"。

**怎么用**：训练时数每个词在垃圾/正常邮件里的频率（词似然）与类别占比（先验）；预测时把词似然连乘、乘先验、归一化，得 P(spam|words)，超阈值拦截。

**类比**：看关键词判邮件——"免费""中奖"出现多就更像垃圾，但用概率严格加权而不是拍脑袋。

**易错点**：假设词之间条件独立（现实中"免费"与"中奖"常共现）；未做平滑时新词会让整个乘积归零。

**前置**：见 kp-09（贝叶斯）、kp-06（独立）、kp-17（多项）。

<a id="kp-40"></a>
### 40. 案例：医疗诊断（Medical Diagnosis）

**直觉**：把第一部分贝叶斯算例放大成真实决策流——医生需要不止一个阳性检测才能下结论。

**是什么**：先验 = 人群患病率；似然 = 检测灵敏度/特异度；贝叶斯定理把两者合成后验。1% 患病率 + 90% 灵敏度 + 95% 特异度 → 阳性后验仅约 15.4%（见 kp-09 计算）。

**为什么**：回扣开头的 Think-Pair-Share：90% 灵敏度的检测不代表阳性即 90% 患病——贝叶斯网络能把多个检测、症状、专家先验一致地合并，给出更可靠的后验。

**怎么用**：P(disease|test) 从患病率和检测指标算出；多个证据用贝叶斯网络合并，而非单个测试下结论。

**类比**：单一检测像"一条线索"，多检测+先验像"完整证据链"，后者才撑得起结论。

**易错点**：再次强调——灵敏度 P(+|disease) ≠ 后验 P(disease|+)。

**前置**：见 kp-09、kp-32。

<a id="kp-41"></a>
### 41. 案例：推荐系统（Recommendation Systems）

**直觉**：把用户和物品都嵌入"潜在因子"，用贝叶斯方法给预测附上不确定性区间。

**是什么**：贝叶斯矩阵分解（Bayesian matrix factorization）：潜在用户/物品因子各配先验，对评分矩阵（大多为空）做分解。推断：计算潜在因子上的后验，预测评分并给出不确定性区间。决策：如"预测 4 星，80% 置信"，高不确定性驱动谨慎探索（新用户/新物品尤其难）。

**为什么**：推荐不仅要点预测，还要知道"这个推荐我有多少把握"，不确定性高时不该贸然强推。

**怎么用**：用户×物品评分矩阵大部分为空；用潜在因子刻画用户偏好与物品属性，先验约束因子，后验给预测区间。

**类比**：给新同学推荐课程——他的记录少（不确定），与其硬推，不如多试几门探探（探索）。

**易错点**：新用户/新物品是"冷启动"难点，不确定性天然很高，需要探索策略。

**前置**：见 kp-30（完整贝叶斯）、kp-19（高斯先验）。

<a id="kp-42"></a>
### 42. 案例：图像分割（Image Segmentation）

**直觉**：逐像素看颜色证据 + 邻居一致性约束，两者合起来把前景/背景切干净。

**是什么**：问题：按颜色把每个像素标为前景/背景。概率模型：P(Y|X) ∝ exp(Σᵢ log P(Xᵢ|Yᵢ) + β Σ 邻居一致性)——MRF/CRF 形式，第一项是逐像素颜色证据，第二项是相邻像素标签一致的平滑先验（β 控制平滑强度）。推断：MAP 解 ≈ 能量最小化/图割（graph-cut）问题。CRF 后处理把同一思想用于平滑 CNN 输出。

**为什么**：单独阈值化会碎、有噪声；加上"邻居倾向同标签"的结构先验，分割才平滑连贯。

**怎么用**：像素颜色证据 + 邻居一致 → 分割；CNN 粗分割后用 CRF 平滑边界。

**类比**：给地图上色——每个格子按颜色上色，但相邻格子颜色要尽量连续，否则图斑驳。

**易错点**：β 太大过度平滑会抹掉细节边界；MAP 解是能量最小化，不是解析闭式。

**前置**：见 kp-33（MRF）、kp-29（MAP）。

<a id="kp-43"></a>
### 43. 案例：强化学习中的不确定性（Reinforcement Learning Under Uncertainty）

**直觉**：智能体看不到环境的真实状态，只能维护一个"信念分布"，动作选择还要考虑风险而不只是期望回报。

**是什么**：问题：环境部分可观测（partially observable），智能体观察不到真实状态。模型：对可能状态维护信念分布（belief distribution）。推断：每次观测后做贝叶斯更新，用动作条件模型预测下一信念。决策：动作选择可考虑风险（如惩罚方差），不只最大化期望回报。新地标观测使后验信念集中，机器人移动使信念扩散。

**为什么**：RL 不只是"最大化期望奖励"——不确定性和风险同样重要；不知道自己在哪时，乱动可能很危险。

**怎么用**：机器人先有宽信念（不确定位置），移动后扩散，观测到新地标后集中——每一步都更新信念，并按"期望+风险"选动作。

**类比**：雾里开车——看不清路（信念宽），减速谨慎（风险规避），看到路标后信心恢复（信念集中）。

**易错点**：期望回报最大 ≠ 最优，高风险高回报的动作可能该回避；信念是分布，不是单个状态。

**前置**：见 kp-30（贝叶斯更新）、kp-05（方差/风险）。

<a id="kp-44"></a>
### 44. 常见误区汇总（Common Misconceptions）

**直觉**：把整门课最容易踩的八个坑一次性列出来，逐条对照纠正。

**是什么**：八条常见误区：
1. 概率密度 ≠ 概率（连续随机变量单点概率恒为 0）；
2. P(A|B) ≠ P(B|A)，条件方向不能反；
3. 检测阳性 ≠ 高患病后验概率；
4. CLT 不是说原始数据变高斯，而是标准化的样本均值趋近高斯；
5. softmax 置信度不自动是校准过的概率；
6. 独立性是建模假设，不是普适事实；
7. MLE 给点估计，不给完整不确定性图景；
8. 熟悉的高斯不一定是正确的模型。

**为什么**：这些误区反复出现、代价高昂（误诊、过度自信、错误建模），集中复习能形成"防坑清单"。

**怎么用**：每遇到一个结论，先过一遍这八条，问自己是不是踩了其中某个。

**类比**：像驾考前的"易错题清单"——考前扫一遍，考场上少犯错。

**易错点**：每条本身就是一个易错点，记住"方向、密度、校准、假设"四个关键词。

**前置**：见 kp-04、kp-07、kp-09、kp-11、kp-36、kp-06、kp-26、kp-25。

<a id="kp-45"></a>
### 45. 费雪信息与渐近正态性（Fisher Information & Asymptotic Normality）

**直觉**：费雪信息衡量"数据里关于 θ 的信息有多少"——信息越多，估计越准、方差越小。

**是什么**：
- 观测费雪信息：I(θ̂) = −ℓ″(θ̂)，即对数似然在 θ̂ 处的二阶导取负（曲率越大，似然峰越尖，估计越确定）；
- 近似方差：Var(θ̂) ≈ I(θ̂)⁻¹；
- 渐近正态性：正则条件下 MLE 一致（consistent）且渐近正态，√n(θ̂ − θ*) ⇒ Normal(0, I(θ*)⁻¹)；MLE 可达到克拉美-罗下界（Cramér-Rao lower bound）。

**为什么**：给 MLE 的"好性质"一个定量说明，并给出标准误的近似公式，从而构造置信区间。

**怎么用**（指数例子）：30 个等待时间，x̄ = 1.283 小时，λ̂ = 1/x̄ ≈ 0.779/小时；费雪信息 I(λ) = n/λ²，标准误 SE(λ̂) ≈ λ̂/√n = 0.779/√30 ≈ 0.142，近似 95% 区间 [0.500, 1.058]——估计值带着一条量化不确定带。

**类比**：费雪信息像"似然峰的陡峭度"——峰越尖（信息越多），参数位置越确定，误差棒越短。

**易错点**：小样本下 MLE 可能有偏、方差大；边界情况（伯努利全成功 p̂=1）没有自动的不确定性度量；渐近正态是"大样本"性质，n 小不适用。

**前置**：见 kp-26（MLE）、kp-27。
