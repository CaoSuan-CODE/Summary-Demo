# Ch_2(QUIZ VERSION) 知识点摘要

## 一、知识点概述

<a id="sm-01"></a>
### 1. 食物作为社会学议题与身份标记
- 概括："告诉我你吃什么，我就告诉你你是谁。"食物选择标记身份，饮食习惯随地点与时间变化，并伴随各种仪式；食物因此成为观察社会的窗口。
- 📎 详见：[食物作为社会学议题](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-01)

<a id="sm-02"></a>
### 2. 食物不安全与食物不平等
- 概括：食物不安全指无法获得可负担、健康且文化上合适的食物；它与食物生产中的不平等相关，发达国家的"丰裕"背后依然存在食物无保障。
- 📎 详见：[食物不安全](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-02)

<a id="sm-03"></a>
### 3. 社会学三大理论视角及其特征
- 概括：功能主义（涂尔干）、冲突论（马克思、韦伯、女性主义）、互动论（米德、戈夫曼）三副"眼镜"研究社会；每个视角由假设、聚焦面与灵活度三个特征界定，按研究问题选择最合适的视角。
- 📎 详见：[社会学三大理论视角](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-03)、[理论视角的特征](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-04)

<a id="sm-04"></a>
### 4. 商品拜物教与生产过程
- 概括：马克思指出商品把生产过程在消费环节遮蔽；被藏起来的是剥削性、异化性的劳动关系，以及工厂化养殖对动物和环境的代价。
- 📎 详见：[商品拜物教](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-05)、[生产过程中的劳动与自然](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-06)

<a id="sm-05"></a>
### 5. 涂尔干：食物图腾与神圣/世俗
- 概括：图腾是代表群体的动植物；崇拜图腾就是崇拜群体本身，产生社会团结。节日食物（如感恩节火鸡）是神圣的图腾，与世俗的日常食物相对。
- 📎 详见：[图腾、神圣与世俗](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-07)

<a id="sm-06"></a>
### 6. 女性主义与食物劳动
- 概括：多数人反对"食物劳动是女人的活"，但家中无偿食物劳动仍主要由女性承担，观念与行为存在错位；把食物端上桌包含有偿与无偿劳动。
- 📎 详见：[女性主义与食物劳动](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-08)

<a id="sm-07"></a>
### 7. 文化及其要素
- 概括：文化是群体共享的意义系统与模式，含物质文化（实物）与非物质文化（规范、价值观、符号）两类要素。
- 📎 详见：[文化及其物质与非物质要素](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-09)、[规范](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-10)、[价值观](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-14)

<a id="sm-08"></a>
### 8. 越轨、社会控制与制裁
- 概括：越轨是违反社会规范；社会控制通过社会化、监督、制裁三机制让个体符合规范；制裁分正面（奖励）与负面（惩罚）两类。
- 📎 详见：[越轨](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-11)、[社会控制](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-12)、[制裁](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-13)

<a id="sm-09"></a>
### 9. 价值观与价值冲突
- 概括：价值观是对错、重要与否、可取与否的信念，它为规范提供依据并指导行动；当多个价值观互相矛盾、无法同时满足，就出现价值冲突，迫使个体取舍。
- 📎 详见：[价值观](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-14)、[价值冲突](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-15)

<a id="sm-10"></a>
### 10. 文化相对主义与民族中心主义
- 概括：文化相对主义主张结合对方文化理解其信念与行为；民族中心主义则用自己的文化评判他人，常伴"自己文化更优越"的信念。二者是一对相反立场。
- 📎 详见：[文化相对主义](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-16)、[民族中心主义](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-17)

<a id="sm-11"></a>
### 11. 社会学研究取向与定性访谈
- 概括：规范性取向关心社会"应该如何"，经验性取向记录社会"实际如何"；定性访谈是经验研究的工具，用开放式问题深入理解少数受访者的经历与认同，但不追求推广到总体。
- 📎 详见：[规范性与经验性研究取向](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-18)、[定性访谈](Ch_2(QUIZ VERSION)-知识点讲解.md#kp-19)

## 二、知识点联系（概览）
- 食物社会学议题（sm-01）→ 食物不安全（sm-02）：同属食物社会学的观察角度。
- 三大理论视角（sm-03）→ 商品拜物教（sm-04）/ 食物图腾（sm-05）/ 食物劳动（sm-06）：分别是冲突论与功能主义视角的具体运用。
- 食物图腾（sm-05）→ 文化要素（sm-07）：用物质/非物质框架拆解食物图腾。
- 文化要素（sm-07）→ 越轨、社会控制与制裁（sm-08）：规范是文化的非物质要素，社会控制维护规范。
- 文化要素（sm-07）→ 价值观与价值冲突（sm-09）：价值观是文化的非物质要素，冲突源于价值观矛盾。
- 文化相对主义 ↔ 民族中心主义（sm-10）：相反立场，成对理解。
- 研究取向与定性访谈（sm-11）：定性访谈是经验取向的具体工具。
