# L4 QUIZ VERSION 知识点摘要

## 一、知识点概述

<a id="sm-01"></a>
### 1. 阶级、地位与社会流动
- 概括：阶级是把收入、财富、教育、职业声望、生活方式、地位等相近的人归为一层；地位是个人或群体的声望等级；社会流动则是相对出身家庭而言的阶级位置变化。
- 📎 详见：[阶级](L4 QUIZ VERSION-知识点讲解.md#kp-01)、[社会流动](L4 QUIZ VERSION-知识点讲解.md#kp-02)、[地位](L4 QUIZ VERSION-知识点讲解.md#kp-03)

<a id="sm-02"></a>
### 2. 炫耀性消费
- 概括：凡勃伦提出的概念——消费高度可见的奢侈品以向他人发出精英地位的信号，核心在于「可见性 + 信号功能」。
- 📎 详见：[炫耀性消费](L4 QUIZ VERSION-知识点讲解.md#kp-04)

<a id="sm-03"></a>
### 3. 支出级联与向上仿效
- 概括：上层消费标准逐级「滴漏」带动下层开支扩张（支出级联）；肖尔指出如今人们仿效的不再是邻居而是名人（向上仿效），导致欲望持续跑在收入前面（期望落差），且商品一旦普及就失去炫耀价值。
- 📎 详见：[支出级联](L4 QUIZ VERSION-知识点讲解.md#kp-05)、[向上仿效](L4 QUIZ VERSION-知识点讲解.md#kp-06)

<a id="sm-04"></a>
### 4. 布尔迪厄：好品味与三种资本
- 概括：布尔迪厄认为品味既反映又强化不平等，「会挑会用」比「买得起」更重要，社会不平等被自然化为个人品味；他提出经济、社会、文化三种资本，可相互兑换。
- 📎 详见：[布尔迪厄：阶级与"好品味"](L4 QUIZ VERSION-知识点讲解.md#kp-07)、[三种资本](L4 QUIZ VERSION-知识点讲解.md#kp-08)

<a id="sm-05"></a>
### 5. 文化资本的类型
- 概括：文化资本分三种形态——具身化（体现于行为）、客体化（体现于拥有物）、制度化（机构认证）。
- 📎 详见：[文化资本的类型](L4 QUIZ VERSION-知识点讲解.md#kp-09)

<a id="sm-06"></a>
### 6. 公共空间与第三空间
- 概括：公共空间是人人都可合法进入的区域，咖啡馆提供的是「准公共空间」；奥登伯格的「第三空间」是家与工作之外、能遇到并互动于不同背景之人的场所，为社区团结与地方民主奠基。
- 📎 详见：[公共空间](L4 QUIZ VERSION-知识点讲解.md#kp-10)、[第三空间](L4 QUIZ VERSION-知识点讲解.md#kp-11)

<a id="sm-07"></a>
### 7. 咖啡商品链、道德消费与公平贸易
- 概括：商品链是商品从设计到废弃的全路径；「咖啡悖论」指南方种植者危机与北方分销商繁荣并存；道德消费以抵制/反向抵制用钱包表达立场，公平贸易是其制度化形式，却面临「被大公司收编、无法改变全局不平等」等批判。
- 📎 详见：[商品链与咖啡悖论](L4 QUIZ VERSION-知识点讲解.md#kp-12)、[道德消费](L4 QUIZ VERSION-知识点讲解.md#kp-13)、[公平贸易及其批判](L4 QUIZ VERSION-知识点讲解.md#kp-14)

<a id="sm-08"></a>
### 8. 调查研究方法
- 概括：调查研究向有代表性的样本发放标准化问卷并分析回答，是一种定量方法，用于比较总体中不同群体在特征、观点和行为上的差异。
- 📎 详见：[调查研究](L4 QUIZ VERSION-知识点讲解.md#kp-15)

## 二、知识点联系（概览）
- 阶级与地位 → 炫耀性消费（动机）：想展示高地位，于是买「别人看得见」的奢侈品（sm-01 → sm-02）。
- 炫耀性消费 → 支出级联与向上仿效（机制）：上层示范、下层跟风，比较对象从邻居升级为名人（sm-02 → sm-03）。
- 炫耀性消费 → 布尔迪厄的好品味（深化）：从「买得起」推进到「会挑会用」，品味成为阶级再生产的工具（sm-02 → sm-04）。
- 布尔迪厄的三种资本 → 文化资本类型（细化）：文化资本进一步细分为具身化、客体化、制度化（sm-04 → sm-05）。
- 阶级与品味 → 公共空间与第三空间（场景）：咖啡馆等第三空间是不同阶级相遇、消费与展示的舞台（sm-01/sm-04 → sm-06）。
- 阶级不平等 → 咖啡商品链（全球化）：国内阶级差异延展为全球南方危机与北方繁荣并存（sm-01 → sm-07）。
- 商品链不公 → 道德消费与公平贸易（回应）：消费者以抵制/反向抵制回应，公平贸易是其尝试与批判对象（sm-07 内部，及 sm-03 的新消费观）。
- 全部现象 → 调查研究（方法）：调查研究是量化测量阶级、品味、消费习惯与态度的工具（sm-01～sm-07 → sm-08）。
