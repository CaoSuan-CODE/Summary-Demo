# TOPIC 3(quiz VERSION) 知识点摘要

## 一、知识点概述

<a id="sm-01"></a>
### 1. 阶级与雇佣劳动
- 概括：马克思以"与生产资料的关系"把资本主义社会分为无产阶级（工人）与资产阶级（生产资料所有者）；社会学则用收入、财富、教育、职业声望等综合指标界定阶级。雇佣劳动是工人把劳动出卖给雇主的关系，是资本主义的基本规范，也是个人意义的来源。
- 📎 详见：[阶级](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-01)、[雇佣劳动](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-02)

<a id="sm-02"></a>
### 2. 异化
- 概括：异化是资本主义劳动中常见的疏离感，表现为四个面向——对劳动过程、对劳动产品、对其他工人、对自身创造性本性的失控与分离。它是马克思对资本主义劳动条件的核心批判。
- 📎 详见：[异化](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-03)

<a id="sm-03"></a>
### 3. 跨国公司与全球劳动分工
- 概括：跨国公司是跨越国界经营、影响力巨大的全球经济行动者。全球化中资本可自由流动，劳动却受国界管制、更加脆弱；由此就业结构转向低技能低薪的"麦工作"，而非高技能知识型工作。
- 📎 详见：[跨国公司](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-04)、[资本与劳动的全球流动](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-05)、[转向"麦工作"](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-06)

<a id="sm-04"></a>
### 4. 商品链与全球北方/南方
- 概括：商品链追踪商品从设计、制造、零售、消费到废弃的全过程，揭示各环节的权力与利润分配；据此可把世界分为相对富裕强大、制造高价值商品的全球北方，与贫困人口多、影响力小、以出口农作物为主的全球南方。
- 📎 详见：[商品链](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-07)、[全球北方与全球南方](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-08)

<a id="sm-05"></a>
### 5. 意识形态、霸权与文化帝国主义
- 概括：意识形态既指一套相关的信念与态度，也指（马克思主义传统中）掩饰和正当化不平等的扭曲观念。霸权是葛兰西的概念，指渗透进常识、强化支配关系的观念；文化帝国主义则是北方文化在全球的同质化扩张。
- 📎 详见：[意识形态](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-09)、[霸权](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-10)、[文化帝国主义](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-11)

<a id="sm-06"></a>
### 6. 理性化与麦当劳化
- 概括：韦伯认为官僚制（层级组织 + 既定规则）是现代性的标志，其代价是限制个人能动性的"铁笼"。里泽把这一命题搬到消费社会，提出麦当劳化——各类机构采纳快餐店的组织原则，其特征为效率、可计算性、可预测性、控制，并导致"理性的非理性"：对行业理性的安排，对工人、顾客、社会和环境可能非理性。
- 📎 详见：[铁笼](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-12)、[麦当劳化](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-13)、[麦当劳化的四大特征](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-14)、[理性的非理性](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-15)

<a id="sm-07"></a>
### 7. 社会运动
- 概括：社会运动是在正式政治渠道之外、持续而有组织地推动社会变革的努力。其成败可用两种视角解释——资源动员（动员人力、资金、组织能力）与政治过程模型（依赖政治体系的开放与目标的正当性）；框架建构（强调某些方面、淡化另一些方面）则影响运动的正当性。
- 📎 详见：[社会运动](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-16)、[解释社会运动成败的两种视角](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-17)、[框架建构](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-18)

<a id="sm-08"></a>
### 8. 研究方法：民族志
- 概括：民族志是一种微观研究方法——研究者长期沉浸于社会情境、观察并与人们互动，从局内人视角描述和解释行动与经验，适用于深入研究少量个案（如食品生产的某个环节）。
- 📎 详见：[民族志](TOPIC 3(quiz VERSION)-知识点讲解.md#kp-19)

## 二、知识点联系（概览）
- 阶级 → 雇佣劳动 → 异化（因果）：不占有生产资料 → 只能出卖劳动 → 劳动中失去控制而疏离。
- 异化 → 麦工作（应用）：麦工作恰是异化的典型工作形态。
- 跨国公司 → 商品链 → 全球北方/南方（递进）：TNC 组织商品链，链条上的权力与利润分配形成南北分化。
- 阶级 → 意识形态 → 霸权 → 文化帝国主义（递进）：观念从"掩饰不平等"升级为"渗透常识"，再扩展为全球文化同质化。
- 铁笼 → 麦当劳化 → 理性的非理性（继承）：韦伯的理性化命题在消费社会中的当代形态及其代价。
- 社会运动 → 资源动员/政治过程 → 框架建构（递进）：从定义到成败解释，再到正当性的塑造。
