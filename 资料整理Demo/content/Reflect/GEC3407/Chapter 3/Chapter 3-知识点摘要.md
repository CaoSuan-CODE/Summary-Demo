# Chapter 3 知识点摘要

## 一、知识点概述

<a id="sm-01"></a>
### 1. 阶级与雇佣劳动
- 概括：阶级是按收入、财富、教育、职业声望、社会地位等划分的人群；马克思将其分为无产阶级与资产阶级。雇佣劳动是工人向雇主出卖劳动换取工资的关系，是资本主义的常态，也是个人意义感的来源。
- 📎 详见：[阶级](Chapter 3-知识点讲解.md#kp-01)、[雇佣劳动](Chapter 3-知识点讲解.md#kp-02)

<a id="sm-02"></a>
### 2. 异化
- 概括：异化是资本主义劳动中的疏离感，表现为与劳动过程、劳动产品、其他工人以及自身创造本性的四重疏离。
- 📎 详见：[异化](Chapter 3-知识点讲解.md#kp-03)、[异化的四个方面](Chapter 3-知识点讲解.md#kp-04)

<a id="sm-03"></a>
### 3. 全球经济中的资本与劳动
- 概括：跨国公司跨越国界经营并影响全球经济；资本流动性远高于劳动，工人更脆弱；新增就业以低技能低薪"麦工作"为主；商品链勾勒商品从设计到废弃的路径；全球北方与南方按发展程度划分世界分工。
- 📎 详见：[跨国公司](Chapter 3-知识点讲解.md#kp-05)、[资本与劳动的全球流动性](Chapter 3-知识点讲解.md#kp-06)、["麦工作"](Chapter 3-知识点讲解.md#kp-07)、[商品链](Chapter 3-知识点讲解.md#kp-08)、[全球北方与全球南方](Chapter 3-知识点讲解.md#kp-09)

<a id="sm-04"></a>
### 4. 意识形态、霸权与文化帝国主义
- 概括：意识形态是信念体系或为不平等辩护的扭曲观念；霸权指强化支配的观念被嵌入常识；文化帝国主义指全球文化在全球北方影响下趋同。
- 📎 详见：[意识形态](Chapter 3-知识点讲解.md#kp-10)、[霸权](Chapter 3-知识点讲解.md#kp-11)、[文化帝国主义](Chapter 3-知识点讲解.md#kp-12)

<a id="sm-05"></a>
### 5. 韦伯的铁笼与理性化
- 概括：韦伯视官僚制为现代性的标志、理性化的形式；"铁笼"指官僚制对个人能动性的限制。
- 📎 详见：[铁笼](Chapter 3-知识点讲解.md#kp-13)

<a id="sm-06"></a>
### 6. 麦当劳化及其五个特征
- 概括：瑞泽尔提出"麦当劳化"——社会机构采纳快餐店组织原则的过程；其特征为效率、可计算性、可预测性、控制，以及综合后果"理性的非理性"，扩散会导致异化。
- 📎 详见：[麦当劳化](Chapter 3-知识点讲解.md#kp-14)、[效率](Chapter 3-知识点讲解.md#kp-15)、[可计算性](Chapter 3-知识点讲解.md#kp-16)、[可预测性](Chapter 3-知识点讲解.md#kp-17)、[控制](Chapter 3-知识点讲解.md#kp-18)、[理性的非理性](Chapter 3-知识点讲解.md#kp-19)

<a id="sm-07"></a>
### 7. 麦当劳化应用于高等教育
- 概括：将麦当劳化四维度用于分析大学教育，考察高校是否在标准化、量化、可预测、受控方面被"麦当劳化"。
- 📎 详见：[麦当劳大学](Chapter 3-知识点讲解.md#kp-20)

<a id="sm-08"></a>
### 8. 解决方案：伦理消费主义与社会运动
- 概括：面对全球经济的种种问题，两条自下而上的出路：通过"美元投票"的伦理消费主义，以及正式政治渠道之外持续有组织的社会运动。
- 📎 详见：[伦理消费主义](Chapter 3-知识点讲解.md#kp-21)、[社会运动](Chapter 3-知识点讲解.md#kp-22)

<a id="sm-09"></a>
### 9. 社会运动的成功与框架化
- 概括：资源动员和政治过程模型解释社会运动成败；框架化通过选择性强调来塑造理解、影响运动正当性。
- 📎 详见：[社会运动成功的解释](Chapter 3-知识点讲解.md#kp-23)、[框架化](Chapter 3-知识点讲解.md#kp-24)

<a id="sm-10"></a>
### 10. 研究工具：民族志与案例分析
- 概括：民族志是长期沉浸、从内部人视角理解群体的定性方法；"过子姐妹"案例以文化资本、异化、角色丧失解读个体，并反思微观研究的盲区。
- 📎 详见：[民族志](Chapter 3-知识点讲解.md#kp-25)、[案例分析：过子姐妹](Chapter 3-知识点讲解.md#kp-26)

## 二、知识点联系（概览）

- 阶级与雇佣劳动 → 异化（因果）：出卖劳动、失去控制是异化的前提。
- 异化 → 铁笼（呼应）：异化的"失去控制"与铁笼的"限制能动性"同源。
- 跨国公司 → 资本与劳动的全球流动性 → 麦工作（递进）：资本流动不对称导致低薪低技能岗位增多。
- 商品链 → 全球北方与南方 → 文化帝国主义（应用）：全球分工与文化趋同都沿南北结构展开。
- 意识形态 → 霸权 → 文化帝国主义（递进）：观念从"辩护"到"常识化"再到"全球扩散"。
- 铁笼 → 麦当劳化 → 理性的非理性（呼应/综合）：麦当劳化是铁笼的当代版，其代价是理性的非理性。
- 麦当劳化 → 麦当劳大学（应用）：把四维度套到高等教育。
- 商品链 → 伦理消费主义（应用）：看清链条才谈得上用消费投票。
- 社会运动 → 社会运动成功的解释 → 框架化（递进）：先有运动，再解释成败，再争夺框架。
- 民族志 → 过子姐妹案例（应用）：案例是方法的运用，并提示微观研究需补宏观视角。
