# Ch_1quiz version 知识点摘要

## 一、知识点概述

<a id="sm-01"></a>
### 1. 社会学想象力
- 概括：C. Wright Mills 提出的核心视角——把个人问题连接到更大的社会结构与历史背景，既不否认个人选择，又追问社会力量如何塑造个人生活。
- 📎 详见：[社会学想象力](<Ch_1quiz version-知识点讲解.md#kp-01>)

<a id="sm-02"></a>
### 2. 社会结构
- 概括：社会生活中持久、相对稳定的组织模式，包括资本主义、全球商品链、性别不平等及国家/市场/官僚制等制度；虽相对固定，但因由人类行动建构，故可被改变。
- 📎 详见：[社会结构](<Ch_1quiz version-知识点讲解.md#kp-02>)

<a id="sm-03"></a>
### 3. 消费文化
- 概括：一种历史类型的社会，生活必需品作为商品在市场购买，与资本主义相连；其轻松的表达维度与严肃的社会问题（劳动、生计、环境）交织在一起。
- 📎 详见：[消费文化](<Ch_1quiz version-知识点讲解.md#kp-03>)

<a id="sm-04"></a>
### 4. 炫耀性消费与自给经济
- 概括：凡勃伦的炫耀性消费强调消费的信号功能（显示精英地位）；自给经济则作为对照，呈现「自己做自己用」的另一种组织方式。
- 📎 详见：[炫耀性消费](<Ch_1quiz version-知识点讲解.md#kp-04>)、[自给经济](<Ch_1quiz version-知识点讲解.md#kp-05>)

<a id="sm-05"></a>
### 5. 资本主义
- 概括：16 世纪英国起源的经济制度，具五大特征：生产资料私有制、雇佣劳动、市场主导分配（大众消费）、以利润为导向、以增长为导向（无增长则危机）。
- 📎 详见：[资本主义](<Ch_1quiz version-知识点讲解.md#kp-06>)

<a id="sm-06"></a>
### 6. 全球化
- 概括：1970 年代以来日益互联的社会、政治、经济与文化过程；利益与代价在社会之间及社会内部分配不均，商品在不同地方的意义并不相同。
- 📎 详见：[全球化](<Ch_1quiz version-知识点讲解.md#kp-07>)

<a id="sm-07"></a>
### 7. 社会学的发展：马克思、涂尔干、韦伯、马蒂诺
- 概括：马克思批判无产阶级与资产阶级的不平等及剥削；涂尔干追问现代社会靠什么整合；韦伯指出官僚制既高效又去人化；马蒂诺主张纳入边缘群体视角。四人从不同侧面奠定社会学。
- 📎 详见：[马克思](<Ch_1quiz version-知识点讲解.md#kp-08>)、[涂尔干](<Ch_1quiz version-知识点讲解.md#kp-09>)、[韦伯](<Ch_1quiz version-知识点讲解.md#kp-10>)、[马蒂诺](<Ch_1quiz version-知识点讲解.md#kp-11>)

<a id="sm-08"></a>
### 8. 社会学思维框架：物质与文化、结构与能动性、微观与宏观
- 概括：三对互补框架——社会生活兼具物质与文化维度且彼此交叉；结构约束与个人能动性并存，其程度由社会位置塑造；分析分微观（小群体互动与意义建构）与宏观（制度/国家/全球过程）两个交织的层次。
- 📎 详见：[物质与文化](<Ch_1quiz version-知识点讲解.md#kp-12>)、[结构与能动性](<Ch_1quiz version-知识点讲解.md#kp-13>)、[社会位置](<Ch_1quiz version-知识点讲解.md#kp-14>)、[微观与宏观](<Ch_1quiz version-知识点讲解.md#kp-15>)

## 二、知识点联系（概览）

- 社会学想象力 → 社会结构（依赖）：想象力连向的「更大的社会力量」核心就是社会结构。
- 消费文化 → 资本主义（依赖）：消费文化是资本主义相连的历史形态。
- 资本主义 → 全球化（依赖）：全球化的经济过程与资本主义相连。
- 资本主义 → 马克思（应用）：马克思批判的正是资本主义下的阶级不平等与剥削。
- 社会结构 → 结构与能动性（依赖）：结构是可变的结构约束，能动性在其中运作。
- 结构与能动性 → 社会位置（依赖）：社会位置决定能动性的程度。
- 物质与文化、结构与能动性、微观与宏观（并列）：三对思维框架互补叠加，共同构成社会学的基本分析工具。
