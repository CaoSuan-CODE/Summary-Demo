# L2-MLP CNN Transformer(1) 知识点讲解

## 一、知识点讲解

<a id="kp-01"></a>
### 1. 仿射变换与神经元计算（Affine transformation: z = wᵀx + b）

**直觉**：深度网络里最核心、重复次数最多的运算只有两步——先把输入做「加权求和再平移」，再用一个非线性函数「拍一下」，把它变成新的表示。一切复杂网络都是这个基本动作的堆叠。

**是什么**：每个神经元（neuron）对输入向量 x 做一次仿射变换（affine transformation）再经过激活函数 φ：

z = wᵀx + b,   a = φ(z)

其中各符号含义：
- x 是输入向量（input vector），例如一张图展平后的所有像素值；
- w 是权重向量（weights），每个分量表示对应输入分量「有多重要」，由学习得到；
- wᵀx 是 w 与 x 的点积（dot product），即先把对应分量相乘再全部加起来，得到加权和；
- b 是偏置（bias），一个学出来的常数偏移量，让结果整体抬升或压低；
- z 是激活前的值，常称「预激活」（pre-activation）；
- φ 是激活函数（activation function），把 z 变成输出 a（activation）。

**为什么**：如果只有线性运算，无论堆多少层，整体仍然等价于一个线性函数，只能表示直线（二维）或超平面，无法表示弯曲的决策边界。引入 w、b 与 φ 的组合，让网络既能学习「每个输入该占多大分量」（w），又能学习「整体往上还是往下挪」（b），还能弯曲（φ），从而表达复杂规律。

**怎么用**：例子——输入 x = [2, −1]，权重 w = [0.5, 1]，偏置 b = 0.5。先算加权和：z = 0.5×2 + 1×(−1) + 0.5 = 1 + (−1) + 0.5 = 0.5。再套 ReLU（见 kp-03）：a = max(0, 0.5) = 0.5。这个 a 就作为下一层神经元的输入继续传下去。

**类比**：可以把 w 想成一张「评分表」，x 是各项成绩，wᵀx 是加权总分，b 是「保底加分」，φ 是「及格线规则」（比如低于 0 直接记 0）。

**易错点**：注意「学习改变的是 w 和 b，而不是公式本身」。公式 z = wᵀx + b 的结构永远不变，训练只是在调 w、b 的数值；新手常误以为网络在学「更复杂的公式」。

**前置**：无（本讲起点）。

<a id="kp-02"></a>
### 2. 线性层与特征维度变换（Linear layer / feature dimension transformation）

**直觉**：一个线性层（linear layer）就像一台「特征维度转换器」：进一批 B 个 D_in 维向量，出来一批 B 个 D_out 维向量，维度变了，批量不变。

**是什么**：对一批输入（batch）X ∈ ℝ^(B×D_in)，线性层定义为

Y = WᵀX + b

各符号含义：
- B（batch size）：一批里有多少个样本；
- D_in：每个输入样本的特征数（输入维度）；
- D_out：每个输出样本的特征数（输出维度）；
- X：形状 [B, D_in] 的输入矩阵；
- W：形状 [D_out, D_in] 的权重矩阵（课件中 W 为 D_out × D_in，转置后再与 X 相乘）；
- b：形状 [D_out] 的偏置向量，广播（broadcast）加到每个样本上；
- Y：形状 [B, D_out] 的输出矩阵。

**为什么**：神经网络之所以叫「特征变换」，核心就在这一层：它把原始特征（像素、词向量等）线性组合成新的特征。维度变化完全由矩阵乘法的形状规则决定——(B × D_in) 与 (D_in × D_out) 相乘得到 (B × D_out)，这是理解一切网络形状的钥匙。

**怎么用**：把一批 32 张图、每张 784 维（28×28 展平）输入，经过一个「784 → 512」的线性层：X 为 [32, 784]，W 为 [512, 784]，输出 Y 为 [32, 512]。批量 32 不变，特征维度从 784 变成 512。

**类比**：想象 B 个同学、每人填 D_in 道题的答卷；线性层是一个「阅卷标准」，把每人 D_in 道题的原始得分汇总成 D_out 项新指标。同学人数 B 始终不变。

**易错点**：W 的两种写法（[D_out, D_in] 配 WᵀX，或 [D_in, D_out] 配 XW）要分清，做题时先对齐形状：输入最后一维必须等于 W 参与相乘的那一维，否则就是形状不匹配（shape mismatch）。

**前置**：依赖 kp-01 的仿射变换概念。

<a id="kp-03"></a>
### 3. 激活函数（Activation functions: ReLU / Sigmoid / Tanh）

**直觉**：激活函数是网络的「弯曲」来源。没有它，堆再多的线性层也只会得到直线/平面；加上它，网络才能画出弯曲的决策边界（decision boundary）。

**是什么**：常见三种：
- ReLU（Rectified Linear Unit，线性整流单元）：ReLU(x) = max(0, x)，把负数归零、正数原样保留；
- Sigmoid：σ(x) = 1 / (1 + e^(−x))，把任意实数压到 (0, 1)，适合当「概率」；
- Tanh（双曲正切）：tanh(x) = (e^x − e^(−x)) / (e^x + e^(−x))，输出在 [−1, 1]，以 0 为中心。

**为什么**：激活函数把线性运算变成非线性（nonlinearity），使多层网络能够表示曲线和复杂的分类边界。ReLU 计算简单、梯度不易消失，是最常用的默认选择；Sigmoid 常用于把分数转成 0~1 的概率；Tanh 有正有负、以零为中心，早期网络常用。

**怎么用**：课件例子——输入 x = [2, −1]，线性层输出 z = [1.5, −0.5]。经过 ReLU：a = [max(0,1.5), max(0,−0.5)] = [1.5, 0]。负数响应被「抹掉」，正数保留，然后 a 传给下一层。同一批里每个样本都独立地做同样的操作。

**类比**：ReLU 像「半波整流器」——负的信号直接断电、正的信号原样通过；Sigmoid 像「音量旋钮归一化到 0~1 挡位」；Tanh 像「把音量映射到 −1（反向）到 +1（正向）」。

**易错点**：Sigmoid 和 Softmax（见 kp-05）不是一回事：Sigmoid 对单个数值独立压到 (0,1)，Softmax 对一组分数整体归一化成和为 1 的分布。

**前置**：依赖 kp-01 的 z = wᵀx + b。

### 4. 张量形状追踪（Tensor shape tracking）

**直觉**：写神经网络、调 bug 时，最常见的错误不是数学难，而是「形状对不上」。把每一层的张量形状在纸上追踪一遍，就能抓住绝大部分问题。

**是什么**：张量（tensor）是多维数组。一层输入输出用形状列表描述各维长度。课件给的追踪模板：

- Input X： [B, D_in]
- Weights W： [D_out, D_in]
- Bias b： [D_out]
- Pre-activation Z： [B, D_out]
- Output A： [B, D_out]

**为什么**：网络每一层只做「形状确定的变换」。只要记住两条规则——① 批量 B 从头到尾不变；② 特征维度按矩阵乘法规则变化——就能预测任意层的输出形状，从而定位「哪一层写错了」。

**怎么用**：手写数字例子里，形状流是 [32, 28, 28] → [32, 784]（展平）→ [32, 512]（线性层 784→512）→ [32, 256]（线性层 512→256）→ [32, 10]（输出 10 类分数）。每一步都写清楚，检查起来一目了然。

**类比**：像快递流水线：箱子（批量 B）数量不变，但每道工序会改变包裹内部的内容维度（特征数）。核对「箱子数对不对、每箱装多少件」即可。

**易错点**：最容易漏的是展平（flatten）这一步——二维图像 [32,28,28] 要先变成 [32,784] 才能进线性层；以及输出层维度必须等于类别数（10 类就是 10）。

**前置**：依赖 kp-02。

<a id="kp-05"></a>
### 5. 从原始分数到预测：Logits、Softmax 与决策（Logits, Softmax and decision）

**直觉**：网络最后吐出来的不是「答案」，而是一串原始分数（每个类别一个）。要变成「这是几」，还差三步：算分数 → 转概率 → 挑最大的。

**是什么**：三步解码：
1. Logits（逻辑值/原始分数）：网络对每个类别给一个实数分数，分数越高表示越倾向该类；
2. Softmax：把分数转成概率。对第 i 类，softmax_i = exp(s_i) / Σ_j exp(s_j)，其中 s_i 是第 i 类的 logit，分母对所有类别求和。结果每个值在 (0,1) 且总和为 1；
3. 决策（decision）：取概率最大的类别作为答案（argmax），并可选地返回置信度（confidence，即该概率值）。

**为什么**：原始分数没有范围、不能当概率。Softmax 用指数放大差距（大分数更突出）、再除以总和归一，得到可解释的「概率分布」。最终「取最大」是分类的标准做法。

**怎么用**：三类 logits = [2.0, 0.5, 0.1]。指数：e^2≈7.39, e^0.5≈1.65, e^0.1≈1.11，总和 ≈10.15。概率：[0.73, 0.16, 0.11]，取第 1 类，置信度 0.73。

**类比**：像考试后把各科分数折算成「总评百分比」，再挑最高的一科报成绩。Softmax 就是「把分数换算成百分比」的规则。

**易错点**：Softmax 后不要再用 argmax 前的 logits 直接比较——虽然 argmax 结果通常一样，但「概率」才有 0~1 的意义；另注意 Softmax 的指数项 exp 让数值更极端，大分数会占更大比例。

**前置**：依赖 kp-02、kp-03（Sigmoid 对比）。

<a id="kp-06"></a>
### 6. 全连接（稠密）层（Dense / fully connected layer）

**直觉**：全连接层里，每一个输出神经元都与每一个输入特征相连——「人人都见面」，信息完全混合。

**是什么**：稠密层（dense layer / fully connected layer）对每个输入特征向量 x 做：

z = xW + b,   h = φ(z)

- 输入特征 x：形状 [B, D_i]；
- 权重 W：每个输出神经元对应一行权重，覆盖「所有」输入特征；
- 输出特征 h：形状 [B, D_o]；
- 完全连接（fully connected）：每个输出神经元接收来自每个输入特征的信息；
- 可学习参数（learnable parameters）：W 存权重、b 存偏置。

**为什么**：这是最简单、最通用的「信息混合」方式：不做任何假设（不假设空间邻近、不假设先后顺序），把所有输入特征平等地组合。正因无假设，它适合「已经是紧凑特征向量」的输入。

**怎么用**：表格数据、图像展平后的向量、以及各种分类头（classification head）都直接接全连接层。批量 B 不变，特征维度可自由变化（D_i → D_o）。

**类比**：像开一场「全员会议」，每个决策者（输出神经元）都听取所有人（输入特征）的意见，综合后给出自己的结论。

**易错点**：全连接层没有「位置」概念——把图像展平成向量后，像素之间的左右上下关系就丢了（这是后面 kp-10 说 MLP 不适合图像的原因之一）。

**前置**：依赖 kp-01、kp-02。

<a id="kp-07"></a>
### 7. 多层感知机与深层堆叠（Multilayer Perceptron and stacking）

**直觉**：一层全连接只能学「简单组合」，把多层摞起来，网络才能把简单特征一步步组合成更有用的高级特征。

**是什么**：多层感知机（MLP，Multilayer Perceptron）就是多个稠密层 + 激活函数的堆叠。每一层：

h^(l) = φ(W^(l) h^(l−1) + b^(l))

其中 h^(l) 是第 l 层输出、h^(0) = x 是输入，W^(l)、b^(l) 是该层权重与偏置，φ 是激活函数。

**为什么**：数据里的规律常常是「复合」的：第一层学到的简单组合（如边缘、某种数值配比），会被第二层再次组合成更复杂的模式，逐层抽象，最终得到对任务有用的表示。激活函数在每层之间加入非线性，保证层层叠加不等于一个线性函数。

**怎么用**：手写数字识别（见 kp-08）：784 → 512 → 256 → 10，三层堆叠。中间层维度可自己设计，最后一层维度等于类别数。

**类比**：像流水线加工：工人 A 把原料做成零件，工人 B 把零件组装成部件，工人 C 组装成成品。每层只做一小步，合起来完成大任务。

**易错点**：多层不等于「越多越好」，但「至少一层隐藏层 + 非线性」是让它区别于单纯线性模型的关键；若全部激活都是线性，多层会退化成一层线性。

**前置**：依赖 kp-06。

<a id="kp-08"></a>
### 8. 手写数字识别的形状流（Shape flow example）

**直觉**：一个具体例子把前面的抽象全串起来：一批 32 张 28×28 的手写数字图，怎么一步步变成 10 个类别的分数。

**是什么**：手写数字（0–9）识别。形状流：

[32, 28, 28] → [32, 784] → [32, 512] → [32, 256] → [32, 10]

- [32, 28, 28]：32 张灰度图，每张 28 行 28 列；
- 展平（flatten）：28×28 = 784 个像素，变成 [32, 784]；
- 隐藏层 1：784 → 512 特征，[32, 512]；
- 隐藏层 2：512 → 256 特征，[32, 256]；
- 类别分数（class scores）：256 → 10，[32, 10]，10 个类别各一个分数；
- argmax：每行取分数最大的那一列，就是预测的数字。

**为什么**：这是理解「形状变化」的模板例子：批量 32 始终不变，特征维度按层设定变化，最后收敛到类别数 10。学完它，任何 MLP 都能照此追踪。

**怎么用**：输入 32 张图一次性处理（batch），每张图独立走过同一套权重，最后得到 32 行预测。argmax 对每行选最大分数对应的下标（0–9）。

**类比**：像批改 32 份「像素卷子」：先摊平成一行 784 个格子，再经两次「特征提炼」，最后得到每张卷子对 0–9 的打分，取最高分即答案。

**易错点**：展平会丢掉行、列结构（二维布局没了），这正是 CNN 要解决的问题；另外注意「类别分数」还不是概率，要过 Softmax（kp-05）才是概率。

**前置**：依赖 kp-04、kp-06、kp-07。

### 9. MLP 参数计数（Counting MLP parameters）

**直觉**：全连接层的参数量随「输入维度 × 输出维度」快速增长，数一数就能知道模型有多大、为什么图像上会爆炸。

**是什么**：一层线性层的参数量 = D_in × D_out（权重）+ D_out（偏置）。手写数字例子：

- L1：784 → 512：784×512 + 512 = 401,408 + 512 = 401,920；
- L2：512 → 256：512×256 + 256 = 131,072 + 256 = 131,328；
- Logits 层：256 → 10：256×10 + 10 = 2,560 + 10 = 2,570；
- 总计：401,920 + 131,328 + 2,570 = 535,818。

**为什么**：每个「输入—输出」连线就是一个权重，所以全连接层参数是二者的乘积。图像维度高（一张 224×224×3 彩色图展平就有 150,528 维），乘上隐藏层维度，参数量会迅速爆炸，既难训练又易过拟合。

**怎么用**：设计网络时，用「D_in × D_out」快速估算模型规模；发现太大时，就考虑减少隐藏层维度，或改用 CNN（权重共享，见 kp-11）。

**类比**：像「人人握一次手」：n 个人和 m 个人两两握手，握手次数约 n×m。全连接层的参数就是这些「握手」的个数。

**易错点**：别忘了偏置 b 的 D_out 个参数，虽少但计数时要算上；另外权重那一项是「乘积」不是「相加」，容易漏算或错算。

**前置**：依赖 kp-06、kp-08。

### 10. MLP 处理图像的三个缺陷（Why plain MLPs struggle with images）

**直觉**：把图像拍平成向量再进全连接层，看似能跑，实则又「瞎」（丢位置）又「胖」（参数爆）又「死板」（尺寸写死）。

**是什么**：三大缺陷：
1. 展平破坏二维布局（destroys explicit 2D layout）：把 H×W×C 的图像摊成 [B, H×W×C] 的一维向量，像素间上下左右的空间关系信息丢失；
2. 全连接导致参数爆炸（too many parameters）：每个像素都要连到每个神经元，参数量 = 像素数 × 隐藏维度，巨大；
3. 输入尺寸固定（fixed resolution）：全连接层要求固定输入长度，换一种图像尺寸模型就不能直接用，难以跨尺寸复用。

**为什么**：图像有天然的「局部结构」——相邻像素关系紧密，远处像素关系弱；而且同一个模式（如一条竖边）可能出现在图里任何位置。MLP 既没有利用局部性，也没有共享同一个模式检测器，只能靠海量参数硬记，效率极低。

**怎么用**：因此引入 CNN（第三部分）：用「局部、共享」的卷积核替代「全局、独立」的全连接，既保住空间结构，又大幅削减参数。

**类比**：全连接像「把整张照片剪成碎片，让每个人都要看所有碎片」；卷积像「让同一个小放大镜扫过整张照片」，放大镜（核）很小、且全图共用，省力又保留位置。

**易错点**：「MLP 不适合图像」不是绝对禁止，而是效率低；当输入本身就是紧凑特征向量时，MLP 仍是好选择（见 kp-06、kp-27）。

**前置**：依赖 kp-06、kp-09。

<a id="kp-11"></a>
### 11. 卷积核与滑动窗口（Convolutional kernel and sliding window）

**直觉**：卷积核（kernel/filter）是一个小的「局部模式探测器」，它像放大镜一样在整张图上滑动，每停一处就输出一个数字，拼成新的特征图。

**是什么**：一个 K×K 的核（课件用 3×3），在每个滑动窗口位置做「对应元素相乘再相加」：

out[i,j] = Σ_{u,v} W[u,v] · X[i+u, j+v] + b

其中 W[u,v] 是核权重（u,v 遍历核内位置），X 是输入，b 是偏置，out[i,j] 是输出特征图上 (i,j) 位置的值。同一个核在整张图上滑动、权重共享（weight sharing）。

**为什么**：图像里同一模式（边、角、纹理）可能出现在任何位置，共享同一个核就能「一个探测器、到处用」，参数少、还能学到位置无关的模式。局部窗口只看邻近像素，符合「邻近像素关系更紧密」的图像先验。

**怎么用**：课件例子：输入 4×4 数字矩阵，用 3×3 核（如竖边检测核 [1,0,−1; 1,0,−1; 1,0,−1]）滑动相乘相加，得到 6.2 之类的响应填入输出图。核在整张图上扫过，输出一张特征图。

**类比**：像用一个固定图案的「印章」在纸上逐格盖章，每盖一下得到一个印记值；印章图案（核）不变，位置在变。

**易错点**：卷积核是「对应相乘再求和」，不是逐元素相乘；且同一个核全程共享——学习只学这一组小权重，这跟全连接每连线一个权重截然不同。

**前置**：依赖 kp-02（矩阵乘法）、kp-10（动机）。

<a id="kp-12"></a>
### 12. 填充与步长（Padding and stride）

**直觉**：填充（padding）是给输入加一圈「护边」，让边缘像素也能当滑动窗口的中心；步长（stride）决定核每次「跳几步」。

**是什么**：
- Padding：在输入四周补 P 圈值（通常补 0）。原 5×5 输入、P=1 时，变成 7×7；
- Stride：核每次移动的格数 S。S=1 每格都停（重叠多、输出大），S=2 隔一格停（重叠少、输出小）。

**为什么**：不填充时，边缘像素只能被窗口扫到很少几次（当不了中心），信息利用不均；填充让每个像素都能成为窗口中心。步长则用来控制输出尺寸和计算量——大步长得到更小输出、更快计算。

**怎么用**：5×5 输入、3×3 核：P=0,S=1 输出 3×3；P=1,S=1 输出 5×5；P=1,S=2 输出 3×3。3×3 核配「same」填充（保持尺寸）就是 P=1、S=1。

**类比**：padding 像给照片四周加一圈白边，方便相框（窗口）对齐到每个像素；stride 像「跨步走」——一步一格还是两步一格，决定走过整张图要停几次。

**易错点**：「same padding」不是固定值，它随核尺寸变：K=3 时 P=1，K=5 时 P=2（一般公式 P=(K−1)/2，S=1 时）；另外步长太大可能让窗口「走不完」，需用下一节的 floor 公式处理。

**前置**：依赖 kp-11。

<a id="kp-13"></a>
### 13. 输出尺寸公式（Output size formula）

**直觉**：想知道卷积后特征图多大，不用掰手指，一个公式直接算。

**是什么**：输出高度（宽度同理）：

H_out = floor((H + 2P − K) / S) + 1

各参数：
- H：输入的高度；
- P：单边填充圈数；
- K：核尺寸（K×K）；
- S：步长；
- floor(·)：向下取整，处理「窗口走不到头」的情况；
- H_out：输出高度。

**为什么**：窗口每移 S 格，可移动的次数由「(H + 2P − K)/S」决定，再 +1 是因为起点也算一个位置；除不尽时取整。这个公式把 padding、stride、核尺寸对输出大小的影响统一表达。

**怎么用**：H=5、K=3。P=0,S=1 → floor((5−3)/1)+1 = 3；P=1,S=1 → floor((5+2−3)/1)+1 = 5；P=1,S=2 → floor((5+2−3)/2)+1 = floor(4/2)+1 = 3。要「same」尺寸（输出=输入），令 P=(K−1)/2 且 S=1。

**类比**：像算「一条长桌上能摆几个相框」：桌子长 H，加上两边垫片 2P，相框宽 K，每 S 格摆一个，数一数能摆几个。

**易错点**：P 是「单边」填充，公式里是 2P（上下或左右两边）；floor 不能省——当 (H+2P−K) 不是 S 的整数倍时，最后那个窗口放不下，要舍去。

**前置**：依赖 kp-11、kp-12。

<a id="kp-14"></a>
### 14. 通道与多滤波器（Channels and multiple filters）

**直觉**：一个核只能检测一种模式（如竖边）。要同时检测横边、角、纹理等多种模式，就多放几个核，每个核产出一张特征图，这些「图」叠起来就是通道。

**是什么**：输入形状 [B, C_in, H, W]，核库（kernel bank）形状 [C_out, C_in, K, K]：

- 一个滤波器（filter）覆盖「所有」 C_in 个输入通道，即它的权重对每个输入通道都有一份，求和后得到一张空间特征图；
- C_out 个不同的滤波器，产生 C_out 张输出特征图；
- 输出张量形状 [B, C_out, H_out, W_out]。

**为什么**：真实图像（RGB 3 通道）或深层特征（很多通道）都要「跨通道融合」。每个输出通道对应一种模式检测器；C_out 越大，能同时学到的模式越多。通道数从 C_in 变 C_out，正是 CNN 里「特征变丰富」的来源。

**怎么用**：PyTorch 例子里 nn.Conv2d(1, 16, kernel_size=3, padding=1)：C_in=1（灰度）、C_out=16，得到 16 张特征图。后面每层 C_out 通常越来越大（模式更丰富），空间尺寸越来越小。

**类比**：把输入想成「一摞 C_in 张透明胶片」，每个核是一台「多层胶片扫描仪」，同时看穿所有胶片，输出一张新胶片；C_out 台扫描仪就产出 C_out 张新胶片。

**易错点**：核库形状是 [C_out, C_in, K, K] 四维，别跟单个核的 K×K 混淆；每个输出通道由「一个」滤波器（含 C_in 份 K×K 权重）产生，而不是一个 K×K 核。

**前置**：依赖 kp-11、kp-13。

<a id="kp-15"></a>
### 15. 池化：最大池化与平均池化（Max and average pooling）

**直觉**：池化（pooling）是「缩小空间尺寸、保留主要信息」的下采样操作，没有可学习参数，纯粹按规则取数。

**是什么**：用一个窗口（如 2×2）在特征图上滑动，每个窗口输出一个值：
- 最大池化（max pooling）：取窗口内最大值，保留「最强响应」；
- 平均池化（average pooling）：取窗口内平均值，保留「平均响应」。

**为什么**：池化降低空间分辨率，减少后续计算量和参数量；同时带来一点「平移不变性」——图案略微移动，最大值/平均值基本还在，结果更稳健。它还帮助特征图逐步变成适合分类头的小尺寸。

**怎么用**：课件例子 4×4 输入、2×2 窗口：最大池化取每个 2×2 块的最大值，得到 2×2（如 5,6; 8,7）；平均池化取均值，得到 2.75, 3; 3.75, 4。PyTorch 里 nn.MaxPool2d(2) 就是 2×2 窗口、步长 2，把 28×28 减半到 14×14。

**类比**：最大池化像「每个小区只报最高分」，平均池化像「报平均分」——都是在压缩信息、保留概况。

**易错点**：池化「没有可学习权重」，它只是固定规则，别把它跟卷积（有参数）混淆；最大池化会丢掉位置精确度，但换来更小的尺寸和更强的抗干扰性。

**前置**：依赖 kp-11、kp-14。

<a id="kp-16"></a>
### 16. CNN 完整推理流程（CNN inference pipeline）

**直觉**：CNN 的主体是「卷积干」：一堆卷积块把像素逐步提炼成深层特征，最后接一个很短的分类头输出分数。

**是什么**：完整推理（inference，前向传播）流程：

图像 → 特征图 → 深层特征 → 类别分数（class logits）

- 卷积块（conv block）：每个块含卷积 + 激活 + 常用池化，反复堆叠。第 1 块学边缘（低层），第 2 块学纹理与部件，第 3 块学物体级特征（高层）；
- 全局池化（global pooling）：把最后一张特征图压成一个向量（或展平）；
- 分类头（classifier/MLP head）：把池化后的向量映射到各类别的 logits；
- 决策：Softmax + argmax 得到预测类别（如 Dog 0.86）。

**为什么**：视觉处理的大部分工作在「卷积干」里完成——层层提取从低层到高层的特征；分类器只负责最后的「读表打分」。空间分辨率一路下降，通道数一路上升，正是「位置信息逐步抽象成语义信息」的过程。

**怎么用**：设计 CNN 时，按「卷积块堆叠 → 全局池化/展平 → 全连接分类头」搭骨架；随时追踪形状 [B,C,H,W] 的变化（kp-14、kp-15）。

**类比**：像「层层提炼矿石」：先粗筛出大颗粒（边缘），再提纯（纹理），最后浓缩成精华（物体特征），分类头只做最后一步「称重报价」。

**易错点**：注意「空间尺寸递减、通道数递增」是常态而非偶然；另外分类头是 MLP（全连接），卷积部分与全连接部分的分工别混淆。

**前置**：依赖 kp-05、kp-11 ~ kp-15。

<a id="kp-17"></a>
### 17. 自注意力与 Query/Key/Value 三角色（Self-attention: Query, Key, Value）

**直觉**：自注意力让序列里每个 token「直接」从所有其他 token 收集信息，距离再远也能一步通信。每个 token 同时扮演三种角色：查询（Query）、键（Key）、值（Value）。

**是什么**：注意力（attention）三个角色：
- Query（查询）：当前 token 发出的「我想找什么」；
- Key（键）：每个候选 token 挂出的「我是什么标签」，供匹配；
- Value（值）：每个候选 token 真正携带的「可被取走的信息」。

自注意力（self-attention）中，Query 搜索、Key 负责匹配、Value 携带将被收集的信息。每个 token 都生成自己的 q、k、v 三组向量。

**为什么**：序列（文本、视觉块）里「相关的 token 可能离得很远」。卷积只能看局部窗口，MLP 无位置概念；自注意力用「查询—键匹配」实现全局、内容相关的连接——谁相关，由内容决定，而不是由距离决定。

**怎么用**：对一句话「The cat sat on the mat」，6 个 token，每个都算出自己的 q、k、v；每个 token 用它自己的 q 去和所有 token 的 k 匹配，再用匹配权重去取所有 token 的 v。

**类比**：像图书馆检索：你带一张「查询单」（Query）找书，书架上每本书有「标签」（Key），匹配后按相关度从对应的「书内容」（Value）里抄取信息。查单、标签、内容三者角色不同。

**易错点**：q、k、v 都来自同一个输入，是「自」注意力的含义；它们不是三种输入，而是同一输入经过三个不同线性投影得到的三种角色。

**前置**：依赖 kp-02（线性投影）、kp-04（形状）。

<a id="kp-18"></a>
### 18. 注意力分数：Query–Key 相似度（Query–Key similarity scores）

**直觉**：想知道两个 token 多相关，就让「查询」和「键」做一次相似度打分：分数越大，越相关。

**是什么**：对当前 token 的 Query q 与每个候选 token 的 Key k，算相似度（通常用点积）：

s = q · k（或用归一化点积，见 kp-22）

- 一个候选、一个分数；
- 6 个候选 token 就产生 6 个相关分数；
- 句子或当前 token 变了，分数随之变；
- 分数越大，表示匹配越强（在归一化之前）。

**为什么**：这是注意力「找相关」的核心一步。把「谁相关」量化成分数，后面的 Softmax 才能把分数变成「取多少信息」的权重。点积简单高效，且在高维下有明确的几何含义（夹角越小、内积越大）。

**怎么用**：PyTorch 里 scores = Q @ K.transpose(-2, -1)，得到形状 [B, L, L] 的分数矩阵，每个 (i,j) 位置是 token i 的 q 与 token j 的 k 的点积。

**类比**：像「雷达扫描」：你的查询像一束探测波，每个键像一面反射镜，反射强度（分数）越高，说明那个方向越「值得关注」。

**易错点**：分数此刻还「不是权重」、不保证为正、不保证和为 1，必须经过 Softmax 才能当权重用；另外 Q 与 K 相乘要注意转置方向（对最后一维和第二维）。

**前置**：依赖 kp-17。

<a id="kp-19"></a>
### 19. Softmax 注意力权重（Softmax attention weights）

**直觉**：原始分数又乱又没有范围，Softmax 把它们变成「和为 1、全为正」的权重分布，表示每个 token 该被关注多少。

**是什么**：对第 i 个查询的一组相关分数 s_i 做 Softmax：

αᵢ = Softmax(sᵢ) = exp(sᵢ) / Σⱼ exp(sⱼ),   j = 1…n

其中：
- sᵢ：第 i 个候选的原始分数；
- exp：指数函数，放大分数差异；
- 分母 Σⱼ exp(sⱼ)：所有 n 个候选的指数和，用于归一化；
- αᵢ：第 i 个候选的注意力权重。

结果性质：① 每个权重 > 0；② 所有权重之和 = 1；③ 高分得更多权重，但所有分数一起参与比较。

**为什么**：注意力本质是「按比例取信息」。Softmax 把任意实数分数映射成合法的概率分布，让「该取多少」有了统一尺度。指数函数保证最大分数突出，同时小分数也不至于完全消失（都有正权重）。

**怎么用**：课件例子 s = [0.2, 1.5, 0.8, 0.1, 0.3, 0.6]，Softmax 后 α ≈ [0.10, 0.37, 0.18, 0.09, 0.11, 0.15]——分数最高的 1.5 得到最大权重 0.37，其余按比例分配，总和为 1。

**类比**：像「按表现分奖金池」：先把每人得分用指数放大差距，再除以总分，得到每人该拿的比例；总分始终是 100%。

**易错点**：Softmax 是在「分数维」上做（对每个查询的 n 个候选归一），不是对整张矩阵做一次；PyTorch 里 dim=-1 表示对最后一维（候选方向）归一。

**前置**：依赖 kp-05（Softmax 定义）、kp-18。

<a id="kp-20"></a>
### 20. 加权求和与上下文表示（Weighted sum of values / contextual tokens）

**直觉**：拿到权重后，按权重把各候选的 Value「加权平均」，得到当前 token 的新表示——它已经吸收了整条序列的上下文信息。

**是什么**：注意力输出是 Value 的加权和：

out = Σⱼ αⱼ · vⱼ

其中 αⱼ 是第 j 个候选的注意力权重，vⱼ 是第 j 个候选的 Value 向量。步骤：① 缩放（scale）——每个 Value 乘它的权重；② 相加（add）——加权后的 Value 逐元素相加。

**为什么**：Value 携带的是「实际信息」，权重决定「取多少」。加权和让每个 token 的输出 = 「按相关度混合了整条序列的信息」，于是相同的一个 token 词，在不同上下文里会得到不同的表示（如 "bank" 在金融句和河岸句里意思不同）。

**怎么用**：PyTorch 里 output = weights @ V，得到 [B, L, D]——每个查询 token 一个向量，维度等于 Value 的特征维 D。输出与输入 token 数相同、每 token 维度相同，只是「含义」变了。

**类比**：像「小组讨论后写总结」：你按成员靠谱程度（权重）采纳意见（Value），把各人观点加权拼成你自己的总结（新表示）。

**易错点**：加权和是「逐元素」相加，不是拼接；输出形状与 Value 相同（[B,L,D]），别误以为会减少 token 数——注意力只改表示、不减长度。

**前置**：依赖 kp-17、kp-19。

<a id="kp-21"></a>
### 21. 注意力分布矩阵（Attention distribution matrix）

**直觉**：把每个 token 对每个 token 的权重排成一张方阵，就能一眼看清「谁在看谁」。

**是什么**：注意力权重矩阵形状 [L, L]（每行一个查询，每列一个键），课件例子「The cat sat on the mat」6×6 矩阵：

- 行是 Query（谁在看），列是 Key（在看谁）；
- 每行和为 1，是一份完整的注意力分布（attention distribution）；
- 每个 token 有自己的一行分布：如 "cat" 那行对 "sat" 的权重 0.24、对 "the" 0.13……各不相同。

**为什么**：注意力是「每个 token 各自看全局」，所以每个查询都有一整套权重。矩阵形式同时展示全部查询的分布，是理解「内容相关连接」最直观的方式。每行对应一个上下文输出 token。

**怎么用**：读矩阵时，先看对角线（自己对自己的权重），再看行内哪个位置权重最大（最相关），即可判断该 token 主要从谁那里取信息。

**类比**：像班级「互评表」：每行是一个同学给所有人的打分，每行加起来 100 分，看某一行就知道这个同学最看重谁。

**易错点**：「每行和为 1」是硬约束（Softmax 按行做），列不一定和为 1；行是 Query、列是 Key，方向别读反。

**前置**：依赖 kp-19、kp-20。

<a id="kp-22"></a>
### 22. 缩放点积注意力公式（Scaled dot-product attention）

**直觉**：把「算分数 → 缩放 → Softmax → 加权求和」四步写成一条公式，就是 Transformer 里最核心的自注意力公式。

**是什么**：

Attention(Q, K, V) = Softmax( QKᵀ / √D ) V

其中：
- Q、K、V：由输入 X 经三个线性投影得到的 Query、Key、Value 矩阵，形状均为 [B, L, D]；
- QKᵀ：Query 与转置 Key 相乘，得到分数矩阵 [B, L, L]（L 为序列长度）；
- √D：缩放因子，D 是每个 token 的嵌入维度（embedding dimension），用于稳定梯度；
- Softmax：按行（最后一维）把分数变成权重 [B, L, L]；
- 乘以 V：得到输出 [B, L, D]。

**为什么**：点积的值会随维度 D 增大而变大，D 大时分数会进入 Softmax 的饱和区、梯度变小，训练困难。除以 √D 把分数拉回合理范围，是「缩放」（scaled）的由来。

**怎么用**：PyTorch 步骤：scores = Q @ K.transpose(-2, -1)；scores = scores / math.sqrt(x.size(-1))；weights = torch.softmax(scores, dim=-1)；output = weights @ V。L 是序列长度、D 是嵌入维度，每行权重和为 1。

**类比**：像「考试标准化」：卷面分（QKᵀ）随题量（D）变大而虚高，除以 √D 相当于统一难度系数，再按比例（Softmax）排名、按名次分配名额（乘 V）。

**易错点**：缩放的是「除以 √D」而非 D；Softmax 的 dim 是最后一维（-1）；Q、K、V 形状都是 [B,L,D]，最终输出也是 [B,L,D]，长度 L 不变。

**前置**：依赖 kp-17 ~ kp-21。

<a id="kp-23"></a>
### 23. 层归一化 LayerNorm（Layer normalization）

**直觉**：LayerNorm 在每个 token 内部把特征值「拉回同一尺度」，让数值稳定、训练更顺，但不改变 token 数量和特征维度。

**是什么**：层归一化（Layer Normalization）对「一个 token 的 D 个特征」做标准化——先减均值、再除标准差，再做可学习的缩放与平移：

ŷ = (x − μ) / √(σ² + ε) · γ + β

其中 μ 是该 token 各特征的均值，σ² 是方差，ε 是防止除零的小常数，γ、β 是可学习参数。它改变特征值，不改变 token 数、不改变维度 D。

**为什么**：深层网络里数值分布容易偏移（内部协变量偏移），导致训练不稳。LayerNorm 把每个 token 的特征归一，配合残差连接（kp-24）让深层 Transformer 能稳定训练、收敛更快。它「按 token、跨特征」归一，与批归一化（按批、跨样本）不同。

**怎么用**：Transformer 里 LayerNorm 放在每个子层之前（Pre-Norm）：先 LayerNorm，再进注意力或 MLP。每个 token 独立归一，与序列长度无关，适合长度可变的 token 序列。

**类比**：像「给每个同学的各科成绩做标准化」：不管原始分多高，都换算到同一尺度再比较，让每个人的「科目之间」可比。

**易错点**：LayerNorm 是「每个 token 内部跨特征」归一，不是跨 token 归一；它不改变形状 [B,N,D]，只是改数值。

**前置**：依赖 kp-04（形状）、kp-24（配合使用）。

<a id="kp-24"></a>
### 24. 残差连接（Residual connections）

**直觉**：残差连接是给网络开一条「直通小路」：输入原样传过去，子层只负责贡献一个「增量」，最后加起来。

**是什么**：残差连接（residual connection / skip connection）定义为

out = x + F(x)

其中 x 是子层的输入，F(x) 是子层（注意力或 MLP）算出的「更新/增量」，out 是输出。残差路径把输入直接带到输出，再叠加上子层的结果。

**为什么**：深层网络容易出现「梯度消失/退化」——层太深时信息传不回去、模型反而变差。残差连接让梯度有一条「高速直通道」直达浅层，训练更深模型成为可能；同时每层只需学「相对输入的增量」，更易优化。它也保留了早先的信息，避免完全被覆盖。

**怎么用**：Transformer 里每个子层后都有一个残差相加：x + Attention(LayerNorm(x)) 和 x + MLP(LayerNorm(x))。输出既保留旧信息，又加入新结果。

**类比**：像「改稿子」：与其让新作者整篇重写（易丢失原意），不如让他只写「修改意见（增量）」，再叠加到原稿上——原稿始终保留。

**易错点**：残差相加要求 F(x) 与 x 形状完全相同，因此 Transformer 里注意力、MLP 都保持 [B,N,D] 不变；「残差」指学的是增量，不是「丢弃」。

**前置**：依赖 kp-23（通常一起出现）。

<a id="kp-25"></a>
### 25. Transformer 层完整数据流（Transformer layer data flow）

**直觉**：一层 Transformer = 「LayerNorm → 注意力 → 残差相加 → LayerNorm → MLP → 残差相加」。注意力跨 token 混信息，MLP 在 token 内部改特征。

**是什么**：跟着一个 token 序列走完整一层：

1. 输入 tokens：N 个 token，每个 D 个特征，形状 [B, N, D]；
2. LayerNorm：对每个 token 内部特征归一（kp-23）；
3. Self-Attention：每个 token 从整条序列收集上下文（kp-17~22）；
4. 残差相加：把注意力更新加回层输入（kp-24）；
5. LayerNorm + MLP：逐 token 独立变换特征；
6. 残差相加：得到 N 个输出 token，每个仍 D 维。

最终：输入形状 [B, N, D] = 输出形状 [B, N, D]。

**为什么**：这一层把「跨 token 的信息交换」（注意力）和「单 token 内的特征变换」（MLP）分工组合：注意力解决「谁和谁相关」，MLP 解决「每个 token 的特征怎么提炼」，两者都不改变序列长度和维度，因此层可以无限堆叠。

**怎么用**：记牢两条主线——注意力「跨 token 混合信息」，MLP「token 内部变换特征」；两个残差相加让信息前后贯通。

**类比**：像「开会 → 各人更新发言稿 → 各自回家整理笔记」：开会（注意力）交换全局信息，整理笔记（MLP）在个人内部加工，每个环节都保留原稿（残差）。

**易错点**：两个子层是「注意力 + MLP」，不是两个注意力；每个子层前有 LayerNorm、后有残差；全程形状 [B,N,D] 不变。

**前置**：依赖 kp-17 ~ kp-24。

<a id="kp-26"></a>
### 26. Transformer 层的堆叠（Stacking transformer layers）

**直觉**：一层只做一次「交换+提炼」，把同样的层反复堆叠，token 的表示就越来越抽象、越来越「懂上下文」。

**是什么**：把多个 Transformer 层首尾相接堆叠：

X^(l+1) = 第 l+1 层的输出，重复「上下文混合 + token 内特征变换」。

每一层保持每个 token 一个向量，但表示越来越抽象，能表达更复杂、更高层的关系。

**为什么**：单层注意力的「推理深度」有限——一个 token 只能直接看到所有其他 token；多层堆叠后，信息可以逐层传播、反复加工，学到更抽象的语义关系（类比 CNN 从边缘到物体）。同时因为每层形状 [B,N,D] 不变，堆叠天然可行。

**怎么用**：大型语言模型里堆几十上百层；视觉 Transformer（ViT）也堆多层。读架构时数「层数、每层 D（隐藏维度）、注意力头数」即可把握规模。

**类比**：像「多轮讨论」：每轮大家互相交换信息（注意力）再各自消化（MLP），几轮下来共识和表述都更深入。

**易错点**：堆叠的是「完整层」（含注意力和 MLP 及两个残差），不是只堆注意力；层数增加不改变单个 token 的形状，改变的是表示的「抽象程度」。

**前置**：依赖 kp-25。

<a id="kp-27"></a>
### 27. 三种架构对比与选型（MLP vs CNN vs Transformer）

**直觉**：MLP、CNN、Transformer 本质区别在「连接方式」：全连接、局部共享核、全局内容相关注意力。选型就一句话——选连接方式与输入结构匹配的那个。

**是什么**：对比表：

| 属性 | MLP | CNN | Transformer |
|---|---|---|---|
| 自然输入 | 特征向量 | 空间网格（图像） | token 序列 |
| 连接方式 | 稠密（全连接） | 局部、共享核 | 全局、内容相关 |
| 内置假设 | 无局部性 | 邻近像素更相关 | 相关 token 可能很远 |
| 输出 | 特征向量 | 特征图 | 上下文 token 序列 |

**为什么**：每种连接方式对应一种「先验」：CNN 假设「空间邻近」重要，用共享核高效建模局部；Transformer 假设「相关性由内容决定、与距离无关」，用全局注意力建模任意距离的关系；MLP 不假设，通用但参数多、丢结构。选对先验，事半功倍。

**怎么用**：MLP 用于紧凑向量、表格数据、分类头、简单基线；CNN 用于图像、空间传感器网格、识别/检测/分割；Transformer 用于文本、长 token 序列、语言建模、视觉 token、多模态推理；实际系统常组合——如 CNN 提取局部视觉特征 + Transformer 做全局推理 + MLP 做分类头。

**类比**：三种「开会方式」：MLP 是全员大会（人人连线）；CNN 是「分区小组、同一套议题模板在各区复制」（局部共享）；Transformer 是「自由找相关人私聊，不管座位远近」（内容相关）。

**易错点**：不是「越新越好」，是「越匹配越好」；现代系统常混合三种结构，别把它们当成互斥选项。

**前置**：依赖 kp-07、kp-16、kp-25。

## 二、知识点联系

- 仿射变换 → 线性层（依赖）：线性层 z = WᵀX + b 是仿射变换的批量、矩阵形式。
- 线性层 → 激活函数（应用）：线性层输出 z 作为激活函数 φ 的输入，二者构成一个完整神经元。
- 线性层 → 张量形状追踪（应用）：追踪各层 [B, D] 形状，本质是矩阵乘法维度规则的应用。
- 线性层 → Logits/Softmax（应用）：网络最后用线性层产生各类别 logits，再经 Softmax 成概率。
- 全连接层 → MLP（依赖）：MLP 由多个全连接层加激活堆叠而成。
- 全连接层 → MLP 参数计数（应用）：参数 = D_in × D_out + D_out，由全连接的结构直接推出。
- MLP → MLP 图像缺陷（应用）：全连接无局部性、参数爆炸、尺寸固定，是 MLP 处理图像的三大缺陷。
- 卷积核 → 填充与步长（依赖）：核的滑动方式由 padding 和 stride 决定。
- 填充与步长 → 输出尺寸公式（应用）：H_out = floor((H+2P−K)/S)+1 是二者对输出尺寸影响的定量总结。
- 卷积核 → 通道与多滤波器（扩展）：多个核组成核库，每个核产出一张特征图即一个通道。
- 卷积核 → 池化（应用）：卷积块内，卷积提取模式后常接池化压缩空间。
- 输出尺寸公式 → CNN 推理流程（应用）：逐块用公式追踪空间尺寸递减、通道递增。
- 自注意力 QKV → Query–Key 相似度（依赖）：Q、K 点积产生相关分数。
- Query–Key 相似度 → Softmax 权重（依赖）：分数经 Softmax 变成和为 1 的权重。
- Softmax 权重 → 加权求和（依赖）：权重乘 Value 求和得到上下文表示。
- Softmax 权重 → 注意力分布矩阵（应用）：每行的权重即一个 token 的注意力分布。
- Query–Key 相似度 → 缩放点积注意力（应用）：加入 √D 缩放，汇总为完整注意力公式。
- LayerNorm → 残差连接（应用）：二者配合，构成 Transformer 子层的前后处理。
- 自注意力 → Transformer 层数据流（依赖）：注意力是层内「跨 token 混合」的子层，与 MLP 子层、残差、LayerNorm 组合成完整层。
- Transformer 层数据流 → 层堆叠（依赖）：单层结构不变，可反复堆叠成深层网络。
- MLP / CNN / Transformer → 架构对比与选型（依赖）：三种连接方式的差异决定了各自的适用输入与场景。
