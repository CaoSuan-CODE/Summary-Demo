[s40-p000] How to Perform Self-Attention
[s40-p001] The same token participates in attention through three different roles.
[s40-p002] Query searches, Keys support matching, and Values carry the information that will be collected.
[s40-p003] Why does each token compute similarity with its own?
[s41-p000] Step 0: Creating Query, Key, and Value Vectors
[s41-p001] Each input embedding passes through three learned linear projections.
[s41-p002] Every token creates its own q, k, and v vectors before the attention comparison begins.
[s42-p000] Step 1: Query–Key Similarity
[s42-p001] The current token uses its Query to match every candidate Key.
[s42-p002] One candidate, one score
[s42-p003] Six candidate tokens produce six relevance scores.
[s42-p004] Changing scores
[s42-p005] The scores change when the sentence or the current token changes.
[s42-p006] Larger means closer
[s42-p007] A larger score indicates a stronger Query–Key match before normalization.
[s43-p000] Step 2: Softmax Attention Weights
[s43-p001] Softmax turns arbitrary relevance scores into usable weights.
[s43-p002] Positive weights
[s43-p003] Every candidate receives a weight greater than zero.
[s43-p004] Sum equals 1
[s43-p005] The weights form a distribution over candidate tokens.
[s43-p006] Relative importance
[s43-p007] A high score receives more weight, but every score is considered together.
[s43-p008] αᵢ = Softmax(sᵢ) = exp(sᵢ) / Σexp(sⱼ), j=1...n
[s43-p009] s = [0.2, 1.5, 0.8, 0.1, 0.3, 0.6]    α ≈ [0.10, 0.37, 0.18, 0.09, 0.11, 0.15]
[s44-p000] Step 3: Weighted Sum of Values
[s44-p001] Attention weights decide how much information to take from each Value.
[s44-p002] Scale
[s44-p003] Each Value vector is multiplied by its attention weight.
[s44-p004] Add
[s44-p005] The weighted Value vectors are added element by element.
[s44-p006] The same output shape
[s44-p007] The result has one vector per target token and the Value feature dimension.

[s47-p000] Transformer Layer Overview
[s47-p001] A Transformer layer contains two main sublayers and two residual updates.
[s47-p002] Attention mixes information across tokens. The MLP transforms features inside each token.
[s48-p000] Layer Normalization
[s48-p001] LayerNorm stabilizes the feature scale of each token before a sublayer.
[s48-p002] LayerNorm changes feature values, not the number of tokens or the feature dimension.
[s49-p000] Residual Connections
[s49-p001] A residual path carries the input forward while the sublayer contributes an update.
[s49-p002] The output retains earlier information and adds the new result from attention or the MLP.

[s55-p000] Transformer Self-Attention in PyTorch
[s55-p001] This single-head implementation exposes the attention calculation step by step.
[s55-p002] Minimal self-attention
[s55-p003] import math
[s55-p004] class SelfAttention(nn.Module):
[s55-p005]   def __init__(self, d):
[s55-p006]     super().__init__()
[s55-p007]     self.q = nn.Linear(d, d)
[s55-p008]     self.k = nn.Linear(d, d)
[s55-p009]     self.v = nn.Linear(d, d)
[s55-p010]   def forward(self, x):
[s55-p011]     Q, K, V = self.q(x), self.k(x), self.v(x)
[s55-p012]     scores = Q @ K.transpose(-2, -1)
[s55-p013]     scores = scores / math.sqrt(x.size(-1))
[s55-p014]     weights = torch.softmax(scores, dim=-1)
[s55-p015]     output = weights @ V
[s55-p016]     return output, weights
[s55-p017] Attention calculation
[s55-p018] Input tokens X
[s55-p019] [B, L, D]
[s55-p020] Q, K, V projections
[s55-p021] [B, L, D]
[s55-p022] QKᵀ / √D
[s55-p023] Scores [B, L, L]
[s55-p024] Softmax
[s55-p025] Weights [B, L, L]
[s55-p026] Weights × V
[s55-p027] Output [B, L, D]
