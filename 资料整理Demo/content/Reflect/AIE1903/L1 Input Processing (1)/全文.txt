[s19-p000] Mean–Standard Deviation Normalization
[s19-p001] 19
[s19-p002] x' = (x − μ) / σ
[s19-p003] •  Subtract μ: center the data around the mean.
[s19-p004] •  Divide by σ: express values relative to variation.
[s19-p005] •  RGB channels usually use separate μ and σ values.
[s19-p006] •  Negative outputs and values above 1 are normal.
[s19-p007] Example
[s19-p008] x = 0.80, μ = 0.50, σ = 0.25
[s19-p009] x′ = 1.20
[s20-p000] Worked Example: Normalize One RGB Pixel
[s20-p001] 20
[s20-p002] Original pixel: (128, 64, 255)
[s20-p003] Divide by 255
[s20-p004] (0.502, 0.251, 1.000)
[s20-p005] Subtract μ = 0.5
[s20-p006] Divide by σ = 0.25
[s20-p007] Normalized result ≈ (0.008, −0.996, 2.000)
[s20-p008] •  Each channel is processed independently.
[s20-p009] •  The output does not need to stay between 0 and 1.

[s29-p000] Why not One-Hot Vector
[s29-p001] 29
[s29-p002] One-hot
[s29-p003] [0, 1, 0, 0, 0, 0, …]
[s29-p004] •  Small representative capacity
[s29-p005] •  Very high-dimensional vectors
[s29-p006] •  Sparse and discrete
[s29-p007] •  No natural semantic similarity (cosine similarity scores of vectors are all zeros)
[s29-p008] Dense embedding
[s29-p009] [0.70, −0.20, 0.40, …]
[s29-p010] •  Large representative capacity
[s29-p011] •  Flexibly low dimensional (>=2) vectors
[s29-p012] •  Continuous vector
[s29-p013] •  Learned during training
[s29-p014] •  Meaningful token-wise relationships
[s29-p015] Dense embedding converts a discrete symbol into a point in a continuous feature space.
