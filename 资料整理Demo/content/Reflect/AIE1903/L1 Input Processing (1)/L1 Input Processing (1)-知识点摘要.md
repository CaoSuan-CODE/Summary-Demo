# L1 Input Processing (1) 知识点摘要

## 一、知识点概述

<a id="sm-01"></a>
### 01. 像素与颜色
- 概括：图像被拆成带空间位置的像素网格，灰度像素存一个亮度值，彩色像素用 RGB 三通道数值表示颜色；RGB 是加色模型，三通道各取 0–255。
- 📎 详见：[数字图像是像素网格](L1 Input Processing (1)-知识点讲解.md#kp-01)、[RGB 颜色模型](L1 Input Processing (1)-知识点讲解.md#kp-02)

<a id="sm-02"></a>
### 02. 图像的张量表示
- 概括：RGB 图是 H×W×3 的三维张量；存在 HWC（NumPy/文件）、CHW（PyTorch）、BCHW（加批量维）等维度顺序约定，顺序错是常见 bug。
- 📎 详见：[图像形状 H×W×C](L1 Input Processing (1)-知识点讲解.md#kp-03)、[维度顺序与批量维](L1 Input Processing (1)-知识点讲解.md#kp-04)

<a id="sm-03"></a>
### 03. 分辨率与文件解码
- 概括：分辨率由 H×W 决定，像素数随边长平方增长（细节 vs 计算成本）；图像文件是压缩格式，需解码成规范张量并检查形状、通道顺序、类型、数值范围。
- 📎 详见：[分辨率与计算成本](L1 Input Processing (1)-知识点讲解.md#kp-05)、[图像文件与图像张量](L1 Input Processing (1)-知识点讲解.md#kp-06)

<a id="sm-04"></a>
### 04. 图像预处理与数据增强
- 概括：统一规格的预处理流水线为 decode → RGB → resize → crop/pad → rescale → normalize，且推理要与预训练一致；resize/crop/pad 兼作数据增强，降低过拟合、增加多样性。
- 📎 详见：[图像预处理流水线](L1 Input Processing (1)-知识点讲解.md#kp-07)、[调整尺寸、裁剪与填充](L1 Input Processing (1)-知识点讲解.md#kp-08)

<a id="sm-05"></a>
### 05. 归一化与输入错误
- 概括：像素先重缩放到 [0,1]/[-1,1]，再做均值–标准差归一化 x'=(x−μ)/σ，动机是稳定尺度、通道可比、匹配预训练；输入归一化与批/层归一化位置不同，许多"模型错误"其实来自输入准备错误。
- 📎 详见：[像素重缩放](L1 Input Processing (1)-知识点讲解.md#kp-09)、[均值–标准差归一化](L1 Input Processing (1)-知识点讲解.md#kp-10)、[输入归一化与批/层归一化](L1 Input Processing (1)-知识点讲解.md#kp-11)、[常见图像输入错误](L1 Input Processing (1)-知识点讲解.md#kp-12)

<a id="sm-06"></a>
### 06. 文本与词嵌入
- 概括：文本经分词（词/子词/字符）、词表编号、查嵌入矩阵 E∈ℝ^{V×D} 变成稠密向量；对照 one-hot 说明稠密嵌入维度低、连续、可学习，并能表达语义相似性。
- 📎 详见：[文本处理流水线](L1 Input Processing (1)-知识点讲解.md#kp-13)、[分词与子词](L1 Input Processing (1)-知识点讲解.md#kp-14)、[词表与 Token ID](L1 Input Processing (1)-知识点讲解.md#kp-15)、[词嵌入：从 ID 查矩阵](L1 Input Processing (1)-知识点讲解.md#kp-16)、[one-hot 与稠密嵌入](L1 Input Processing (1)-知识点讲解.md#kp-17)、[嵌入空间的语义相似性](L1 Input Processing (1)-知识点讲解.md#kp-18)

<a id="sm-07"></a>
### 07. 位置、掩码与上下文
- 概括：位置嵌入注入顺序、注意力掩码屏蔽填充位；自注意力让 token 之间信息流动，使同一词在不同上下文中表达不同含义。
- 📎 详见：[位置嵌入与注意力掩码](L1 Input Processing (1)-知识点讲解.md#kp-19)、[自注意力的上下文交互](L1 Input Processing (1)-知识点讲解.md#kp-20)

<a id="sm-08"></a>
### 08. 视觉 token 与多模态输入
- 概括：图像分块 + 线性投影变视觉 token，经视觉编码器和投影器对齐维度后与文本 token 拼接成共享序列；分辨率决定视觉 token 数，好输入 = 清晰图像 + 详细提示。
- 📎 详见：[图像分块与线性投影](L1 Input Processing (1)-知识点讲解.md#kp-21)、[视觉编码器与投影器](L1 Input Processing (1)-知识点讲解.md#kp-22)、[多模态输入流水线](L1 Input Processing (1)-知识点讲解.md#kp-23)、[分辨率与视觉 token 数量](L1 Input Processing (1)-知识点讲解.md#kp-24)、[好的多模态输入](L1 Input Processing (1)-知识点讲解.md#kp-25)

## 二、知识点联系（概览）

- 像素 → RGB → 张量形状 → 维度顺序 → 分辨率（依赖/应用）：图像从"带坐标的颜色"逐步变成规范的三维/四维张量。
- 图像张量 → 预处理流水线 → 归一化 → 输入错误规避（应用）：统一规格与数值分布是模型正常工作的前提。
- 文本 → 分词 → 词表 → 嵌入 → 语义相似（依赖）：离散符号经编号、查表变成连续向量，并获得语义关系。
- 嵌入 → 位置/掩码 → 自注意力上下文（依赖）：顺序信息与上下文交互让词义随句子变化。
- 图像 → 视觉 token → 编码器/投影器 → 多模态序列 → 好输入设计（应用）：视觉与文本向量对齐拼接，最终汇入同一 MLLM。
